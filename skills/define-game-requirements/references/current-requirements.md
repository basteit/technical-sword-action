## ステータス凡例

- `[確定]`: ユーザーが明示的に決定した内容
- `[方針]`: 個別仕様を判断する上位の設計意図
- `[仮置き]`: 未確定部分を補う推奨初期値
- `[未決]`: 影響が大きく、後で明示決定が必要な内容
- `[追加範囲]`: 必須範囲の完成後に着手する拡張候補
- `[廃止]`: 現在は採用しない古い前提

## 0. 最優先の方針更新

- `[確定]` 本作のジャンルはソウルライクではなく、2D剣戟アクションRPGとする。
- `[確定]` 難易度の高さ自体を作品の中心価値にしない。
- `[確定]` ゲームが上達する喜びを、アクション初心者を含む多くの人が享受できる作りにする。
- `[確定]` 中級者があっけなく感じないよう、難易度選択を用意する。
- `[廃止]` 「玄人向け」「高難度だから価値がある」「ソウルライクとして設計する」という表現を現行コンセプトに使用しない。
- `[方針]` 休憩所、回数制回復などに他作品と共通する仕組みがあっても、作品分類や難しさの根拠にはしない。

## 1. 作品定義

### 1.1 概要

- `[確定]` ジャンル: 2D剣戟アクションRPG
- `[確定]` Steamでの発売を予定する。
- `[方針]` 一言説明: パリィと回避から鋭い反撃へ転じる爽快感と、操作を覚えるほど戦い方が広がる上達感を楽しむ作品
- `[確定]` 全3ステージを想定する。
- `[確定]` 基本は一本道で、寄り道、任意ボス、探索報酬によって選択の幅を加える。
- `[方針]` 完全なメトロイドヴァニア構造にはしない。
- `[方針]` 1年程度の開発期間を基準に、戦闘品質をコンテンツ量より優先する。

### 1.2 ターゲット

- `[確定]` 2Dアクションを楽しみたいプレイヤー
- `[確定]` アクション初心者から中級者以上まで
- `[方針]` 標準難易度では、操作を学べば突破できる分かりやすさを求める層
- `[方針]` 高難易度では、読み合いと最適な対処を磨きたい層

### 1.3 体験の柱

1. `[方針]` 敵の予兆を読み、パリィまたは回避し、大きな反撃へ転じる爽快感
2. `[方針]` 成功理由と失敗理由が理解でき、再挑戦ごとに上達を感じられる公平さ
3. `[方針]` 初期から豊富な操作が使え、入力に対して素早く格好良く反応する手触り
4. `[方針]` 小技、必殺技、装備スキルの組み替えによる戦い方の自由
5. `[方針]` 明るい冒険感とクールな剣戟演出を損なわないテンポ

### 1.4 非目標

- `[確定]` 極端な高難度を前提にプレイヤーを選別しない。
- `[方針]` 敵HPの多さだけで歯ごたえを作らない。
- `[確定]` 進行必須の追加移動能力を段階的に解放する構造にしない。
- `[方針]` 大量の説明、暗い悲劇、頻繁な会話停止を主役にしない。
- `[方針]` 広大な相互接続マップや大量のバックトラッキングを必須にしない。

## 2. コアゲームループ

1. ステージを進み、敵、NPC、オブジェクト、任意ルートを発見する。
2. 通常攻撃、パリィ、回避、必殺技を組み合わせて敵を倒す。
3. 敵撃破でポイントを得て、休憩所または拠点で小技スキルを解放、付け替えする。
4. 中ボスとボスで学んだ対処を試し、ボス撃破で新しい必殺技を得る。
5. 次のステージへ進み、機械文明と主人公の過去を断片的に知る。

- `[仮置き]` 死亡時に強化ポイントを失わない。再挑戦への心理的負担を抑える。
- `[確定]` HPが0になると直前の休憩所から復活する。
- `[確定]` ボス戦中の死亡はボスエリア付近から再開し、再戦までの移動を短くする。
- `[仮置き]` ボス再戦時は長い会話や演出をスキップ可能にする。

## 3. プレイヤーアクション

### 3.1 初期から使える基本操作

- `[確定]` 左右移動
- `[確定]` ジャンプ
- `[確定]` 下入力とジャンプによる薄い床のすり抜け
- `[確定]` 4段の通常攻撃。最終段は高威力とする。
- `[確定]` 前方へ一定距離を移動し、無敵時間を持つダッシュ
- `[確定]` 敵の攻撃を弾いてひるませるパリィ
- `[確定]` 必殺ゲージを消費する必殺技
- `[確定]` 通常攻撃、ダッシュ、パリィ、必殺技は空中でも使用可能とする。
- `[確定]` パリィ成功後の追撃は初期能力とし、スキルツリーへ置かない。

### 3.2 操作上の仮置き

- `[仮置き]` 空中ダッシュは着地まで1回とし、着地で回数を回復する。
- `[仮置き]` 通常攻撃の先行入力を6F程度受け付け、入力抜けを抑える。
- `[仮置き]` 4段コンボは1から3段目をつなぎやすくし、4段目は高威力と引き換えに後隙を大きくする。途中で防御行動へ移る判断と、最終段まで出し切る判断の両方を成立させる。
- `[仮置き]` 被弾直後を除き、通常攻撃からダッシュまたはパリィへ限定的にキャンセルできるよう調整する。
- `[未決]` 4段通常攻撃の各段ダメージ、発生、持続、後隙、キャンセル受付の最終値
- `[未決]` 入力レイアウト、対応コントローラー、キーボード操作の標準割り当て

## 4. 戦闘リソース

### 4.1 HPと回復

- `[仮置き]` プレイヤーHP基準値は100とする。
- `[確定]` 回復アイテムの最大使用回数は3回とする。
- `[確定]` 休憩所で回復アイテムを補充する。
- `[仮置き]` スタンダードの1回当たり回復量は最大HPの40%とする。
- `[仮置き]` 回復中も短い移動を可能にし、完全停止による不快感を避ける。

### 4.2 休憩所

- `[確定]` 中継、セーブ、回復補充、スキル付け替えに使用する。
- `[仮置き]` 休憩で倒した通常敵を再配置するが、中ボスとボスは復活させない。
- `[仮置き]` オートセーブを休憩、ボス撃破、重要アイテム取得時に行う。

### 4.3 必殺ゲージ

- `[確定]` 最大値は100とする。
- `[確定]` 攻撃ヒット、パリィ成功、被ダメージで蓄積する。
- `[確定]` 高威力、大範囲の必殺技は60から80を消費する。
- `[確定]` 低威力、小回り型の必殺技は30から50を消費する。
- `[仮置き]` 通常攻撃1から3段目は各+2、4段目は+5、パリィ成功は+10、被ダメージは+8を基準にする。旧3段案と同じコンボ合計+11を保ち、4段化だけで必殺技の回転率が上がりすぎないようにする。
- `[仮置き]` 1回の多段攻撃によるゲージ獲得に上限を設け、密集敵での過剰回収を防ぐ。
- `[仮置き]` ゲージは通常戦闘間で持ち越し、死亡時は50を上限として保持する。

## 5. パリィ、回避、反撃

### 5.1 パリィ

- `[方針]` 狙って成功した実感を残しながら、スタンダードでは厳しすぎない受付にする。
- `[確定]` 連発を制限し、無計画な連打だけでは安定しないようにする。
- `[確定]` 正面かつ近距離の対象には軽い吸い付き補正を行う。
- `[確定]` 背面または高低差が大きい対象には吸い付かない。
- `[仮置き]` スタンダードの成功受付は発生後5Fから18Fとする。
- `[仮置き]` 空振り硬直26F、再使用クールダウン14Fとする。
- `[仮置き]` 成功時の敵ひるみ32F、プレイヤー硬直10F、ゲージ増加+10とする。

### 5.2 パリィ不可攻撃

- `[確定]` 種類を細分化しすぎず、基本対処をジャンプまたはダッシュに統一する。
- `[確定]` 通常攻撃と異なる強い予兆演出を使用する。
- `[確定]` 特殊対策スキルで対処できる場合は、大ダメージ、スタン、ゲージ増加など大きな報酬を与える。
- `[方針]` 専用対策スキルがなくても、基本操作で安全に回避できるようにする。

### 5.3 ダッシュ

- `[確定]` 前方へ一定距離を無敵状態で移動する。
- `[仮置き]` 全体20F、主移動12F、無敵4Fから12Fを初期検証値とする。
- `[方針]` 回避成功後に素早く反撃へ移れるようにし、回避だけで戦闘が途切れないようにする。

### 5.4 視認性

- `[確定]` 通常攻撃には予備動作と攻撃直前の光エフェクトを付ける。
- `[確定]` パリィ不可攻撃には、通常の光と混同しない形、色、音を組み合わせる。
- `[方針]` 色だけに依存せず、姿勢、輪郭、効果音でも区別可能にする。

## 6. 難易度とアクセシビリティ

### 6.1 難易度プリセット

- `[確定]` 難易度選択を実装する。
- `[仮置き]` アシスト、スタンダード、チャレンジの3段階とする。
- `[仮置き]` スタンダードを開発時の基準バランスとする。

| 項目 | アシスト | スタンダード | チャレンジ |
| --- | ---: | ---: | ---: |
| 敵与ダメージ倍率 | 0.75 | 1.00 | 1.20 |
| パリィ受付終了 | 22F | 18F | 15F |
| 敵の攻撃頻度目安 | 0.85 | 1.00 | 1.15 |
| 回復量 | 最大HPの50% | 最大HPの40% | 最大HPの35% |
| ボスHP倍率 | 0.90 | 1.00 | 1.00 |

- `[方針]` チャレンジでもHPを大幅に増やさず、敵の判断要求と攻防密度で歯ごたえを作る。
- `[仮置き]` 難易度は開始時とオプションから変更可能にし、変更ペナルティを設けない。
- `[仮置き]` 難易度によってステージ、ボス、物語、必殺技、主要報酬を制限しない。
- `[仮置き]` 同一ボスで3回以上敗北した場合だけ、アシストへの変更案内を任意表示する。

### 6.2 個別アシスト

- `[仮置き]` 画面揺れ、フラッシュ、ヒットストップ、振動の強度を変更可能にする。
- `[仮置き]` キーコンフィグ、字幕、文字サイズ、効果音と音楽の個別音量を用意する。
- `[仮置き]` 攻撃予兆は色覚だけに依存しない。
- `[仮置き]` チュートリアル再確認と安全な練習場所を拠点に用意する。

## 7. 成長とビルド

### 7.1 基本方針

- `[確定]` 純粋なステータス強化は控えめにする。
- `[確定]` ボス撃破で必殺技を追加する。
- `[確定]` 敵撃破で得るポイントを使い、小技や補助アクションを解放する。
- `[確定]` 進行必須の追加アクションを設けず、戦闘の多様化と移動の快適化に使う。
- `[確定]` 主人公は最初から多くのことができ、不自由さを感じにくい設計にする。

### 7.2 スキルツリー

- `[確定]` 上位ノードの取得を前提とする分岐型ツリーにする。
- `[確定]` 一つの枝を一直線に深く進める取得方法も、同じ深さを横に広げる方法も成立させる。
- `[確定]` 解放済みスキルは休憩所で自由に付け替え、ビルドを試せるようにする。
- `[仮置き]` スキル解放は永続とし、装備枠4枠によって同時使用数を制限する。
- `[仮置き]` 通常雑魚1、変則雑魚2、小ボス級5、中ボス15、ボス30ポイントを基準報酬とする。
- `[仮置き]` ノードコストは浅層5、中層10、深層15を基準にする。
- `[方針]` 通常進行だけで各ステージ中に2から3個の新スキルを試せる獲得量にする。

### 7.3 現行スキル案

- コンボ短縮派生: 2段目から派生技へ移行する。
- 必殺キャンセル: 通常攻撃の終わり際を必殺技でキャンセルする。
- 弱点看破: 連続ヒット後、短時間だけ攻撃効率を上げる。
- 受け流し反射: パリィ成功時に飛び道具を敵へ反射する。
- 回避ゲージ回収: ジャスト回避成功時に必殺ゲージを微回収する。
- 空中受け身: 吹き飛び中に体勢を立て直す。
- 空中ダッシュ斬り: 空中ダッシュ中に突進斬りを出す。
- 着地衝撃: 空中攻撃後の着地時に小範囲のひるみ判定を出す。
- 疾風歩法: ダッシュ後の減速を軽減する。

## 8. 敵と遭遇

### 8.1 敵カテゴリ

- `[確定]` 通常雑魚
- `[確定]` 変則的な動きをする雑魚
- `[確定]` 道中の小ボス級雑魚
- `[確定]` 各ステージの中ボス
- `[確定]` 各ステージのボス
- `[追加範囲]` 隠しボス

### 8.2 遭遇方針

- `[確定]` 序盤から一部で複数体を出す。
- `[方針]` 複数戦では同時に予兆を読めない状況を避け、攻撃役と待機役を制御する。
- `[確定]` 通常雑魚と変則雑魚は、パリィ後の派生攻撃でほぼ一撃にする。
- `[確定]` 小ボス級雑魚は、1回のパリィ反撃では倒れないHPにする。
- `[確定]` 中ボスとボスは、小さな反撃だけでは決定打にならないようにする。
- `[確定]` 中ボスとボスの連続攻撃または大技への対処成功時は、大きな反撃機会を与える。

### 8.3 HP目安

プレイヤー通常攻撃1段目の基準ダメージを10、プレイヤーHPを100とする仮設定である。

| 敵種 | ステージ1 | ステージ2 | ステージ3 |
| --- | ---: | ---: | ---: |
| 通常雑魚 | 30 | 40 | 55 |
| 変則雑魚 | 40 | 55 | 70 |
| 小ボス級雑魚 | 120 | 170 | 230 |
| 中ボス | 350 | 480 | 650 |
| ボス | 900 | 1200 | 1600 |

### 8.4 パリィ反撃倍率

- `[確定]` 通常雑魚、変則雑魚: 3.0倍
- `[確定]` 小ボス級雑魚: 2.0倍
- `[確定]` 中ボス、ボスの通常反撃: 1.5倍
- `[確定]` 中ボス、ボスの大技後反撃: 3.0倍

### 8.5 敵攻撃の被ダメージ目安

- `[仮置き]` 通常雑魚: 8から12
- `[仮置き]` 変則雑魚: 10から14
- `[仮置き]` 小ボス級雑魚: 14から20
- `[仮置き]` 中ボス: 18から28
- `[仮置き]` ボス: 22から35
- `[仮置き]` 危険攻撃: 30から45

## 9. ステージとコンテンツ

### 9.1 全体構成

- `[確定]` 全3ステージを基本とする。
- `[確定]` 各ステージに中ボス1体とボス1体を置く。
- `[方針]` 一本道を主軸にし、短い分岐、任意戦闘、隠し要素で選択幅を作る。
- `[追加範囲]` 隠しボスは本編3ステージと必須ボスの完成後に着手する。

### 9.2 ステージ1: 森

- `[確定]` 主人公が放浪していた地域とする。
- `[確定]` 自然と風化した機械が融合し、遺構が森に飲み込まれつつある景観にする。
- `[確定]` 明るく入りやすい冒険の始まりを表現する。
- `[確定]` 聞き込み、武器強化、練習が行える拠点を置く。
- `[仮置き]` ボスは機械文明の影響を受けた獣、または遺構を守る門番とする。

### 9.3 ステージ2: 街と研究所

- `[確定]` 活気ある未来的なネオン繁華街と、冷たく閉鎖的な研究所を対比させる。
- `[確定]` 華やかさの奥に薄暗い側面をにじませる。
- `[仮置き]` メインボスは研究所を維持する責任者または研究者とする。
- `[仮置き]` 主人公を逃がした蛇モチーフの研究者とは別人物にし、蛇は任意導線へ残す。

### 9.4 ステージ3: 最終領域

- `[確定]` 主人公と同じ研究所で作られた存在との対決場所とする。
- `[確定]` 無機質さ、人工性、鋭さを持つ最終決戦の景観にする。
- `[確定]` 悲劇性より、クールさと敵の格を前面に出す。
- `[確定]` ラスボスはイブをモチーフとするロボットとする。

## 10. 世界観と物語

- `[確定]` 中世を基盤とする世界で、異常発達した機械技術による大戦から数十年後を描く。
- `[確定]` 主人公は大戦期に作られたロボットだが、記憶を失い、自分を放浪の旅人だと思っている。
- `[確定]` 主人公が拾った剣も大戦期の産物で、会話可能なAIを搭載する。
- `[確定]` 主人公とラスボスはアダムとイブをモチーフとする。主人公をアダム、ラスボスをイブとして扱う。
- `[確定]` 主人公を研究所から逃がした研究者は蛇をモチーフとする。
- `[方針]` 蛇の研究者は物語の真相を担う任意ボス候補とし、メイン進行で説明しすぎない。
- `[確定]` 真相はNPCへの聞き込み、オブジェクト、遺構、剣との会話から断片的に伝える。
- `[方針]` 主要イベントは短くし、戦闘と探索の流れを優先する。

## 14. 受入条件とプレイテスト指標

- `[仮置き]` ステージ1のチュートリアル後、初見プレイヤーが通常攻撃とパリィ不可攻撃の予兆を説明できる。
- `[仮置き]` 通常攻撃は1から4段目まで各段で異なる動きと1回の攻撃判定を持ち、4段目のダメージが1から3段目の各単発ダメージを上回る。追加入力がない場合や最終段終了後は操作不能状態を残さず通常状態へ戻る。
- `[仮置き]` 60fps基準で通常攻撃の見た目と攻撃判定のずれを2F以内にし、6Fの先行入力で段飛ばしや入力抜けを起こさない。
- `[仮置き]` アシストではアクション初心者が練習を経てステージ1ボスを突破できる。
- `[仮置き]` スタンダードでは初心者が失敗理由を理解でき、中級者もパリィ、回避、必殺技を使う方が明確に有利と感じる。
- `[仮置き]` チャレンジでは中級者が単調な通常攻撃だけで安定せず、敵の連続攻撃と大技へ適切に対処する必要がある。
- `[仮置き]` 通常雑魚は各ステージでパリィ追撃によりほぼ一撃、小ボス級は一撃で倒れない。
- `[仮置き]` ボスの小攻撃反撃と大技後反撃に、プレイ中に認識できる威力差と演出差がある。
- `[仮置き]` 複数戦でも画面外またはエフェクト裏から回避不能な攻撃を受けない。
- `[仮置き]` ボス敗北から操作可能な再戦状態までの待ち時間を15秒以内にする。
- `[仮置き]` 難易度を変更しても進行データ、物語、主要報酬が失われない。
