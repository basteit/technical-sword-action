# 現行要件ベースライン

この文書は `define-game-requirements` が参照する、現時点のゲーム要件の基準である。会話内の最新の明示決定が本書より優先される。

## 2026-10-19 更新：プロトタイプの反撃演出（#33 / #49）

- `[確定]` 動画と同様の暗転、実際に弾いた敵の背後への移動、命中時の大きな吹っ飛ばしをプロトタイプのパリィ反撃へ接続する。従来の本編地上踏み込み反撃へ演出だけを重ねるのではなく、当該Sceneの専用プロファイルとして選択する。
- `[仮置き]` 最新動画を初期値とし、移行0～12F／背後移動10～12F、タメ12～20F・0.15倍・実時間約0.9秒、命中21F、終了45F、吹っ飛び最大3.2unit・高さ0.65unit・22Fとする。動画と同様に行動中は無敵・任意キャンセルなし、終了前6Fの次反撃予約を許可する。基準威力30と敵別倍率、個体ストック、1入力1対象1Hit、強ザコの反撃耐久は維持する。
- 背後への経路は地形で検証し、開始できない対象のストックは消費しない。開始後の対象消失・中断・死亡・Disable・Scene変更・リセットで対象拘束、重力、無敵、暗転、残光、VFX、吹っ飛び、時間倍率を復帰する。演出設定0%でも移動・時間・判定は変更しない。
- 本編の固定画角と共通Feedbackによるカメラ所有権を保ち、撮影用ズーム・Directorは接続しない。受領原稿・共用PNG・動画用設定は保持する。詳細と新しい受入条件は[反撃演出接続](../../../docs/prototype-counter-cinematic.md)を参照。前版のコントローラー以外の確認完了というユーザー報告と、新反撃の受入は区別する。

## 2026-10-18 更新：プロトタイプの背景と足場（#49）

- プロトタイプの背景は、動画制作で使用している既存の白グリッドを再利用する。新しい背景画像・背景アートは制作しない。
- 基本アクション確認用に足場を数個配置する。通常のブロックとすり抜け床でジャンプ・空中行動・床抜けを確認でき、失敗しても安全な床へ戻れる構成とする。
- 現時点では敵の配置を行わず、初期状態と通常リセットは敵なしにする。実装済みの敵と戦闘検証プリセットは保持し、必要時に明示的に有効にする。敵配置・戦闘受入の最終完了を今回の足場整備と混同しない。

## 2026-10-17 更新：敵別調整と開発運用（#52 / #38）

- 敵HPは敵種別データと配置個体の上書きで調整する。通常雑魚は到達水準の反撃ほぼ一撃を目安とするが、カテゴリによる即死を強制しない。重量などの強ザコは元カテゴリのまま反撃1回に耐えるHPとし、小ボス報酬・再出現ルールへ自動変更しない。
- 反撃倍率、軽／強ひるみ、攻撃中断耐性を独立に調整できる。#52の初期検証値は変則カテゴリ・HP120・反撃倍率3.0、基準反撃90ダメージ。最終バランスの受入は人が行う。
- 開発はmain、Issueごとのチャット／タスク・短命ブランチ・Draft PR、小さなIssue番号付きコミット、Squash mergeを原則とする。複数Issueの一括実装はユーザーが明示した場合だけ例外を記録する。
- mainはPR経由・削除禁止・force push禁止・線形履歴を要求する。承認人数と未安定CIは必須化しない。Unity資産の.metaと生成物除外を確認する。実行手順と設定の正本は[リポジトリ運用](../../../docs/repository-workflow.md)。
- 今回の実装と前回5 Issueの人間向け受入は[統合チェックリスト](../../../docs/prototype-human-acceptance.md)へまとめる。自動テストの合格を操作感・素材・公開判断の承認に読み替えない。

## 1. 作品定義

### 1.1 概要

- `[確定]` ジャンル: 2D剣戟アクションRPG
- `[確定]` Steamでの発売を予定する。
- `[方針]` 一言説明: パリィと回避から鋭い反撃へ転じる爽快感と、操作を覚えるほど戦い方が広がる上達感を楽しむ作品
- `[確定]` 全3ステージを想定する。
- `[確定]` 基本は一本道で、寄り道、任意ボス、探索報酬によって選択の幅を加える。
- `[方針]` 完全なメトロイドヴァニア構造にはしない。
- `[方針]` 1年程度の開発期間を基準に、戦闘品質をコンテンツ量より優先する。

### 1.2 ターゲット

- `[確定]` 2Dアクションを楽しみたいプレイヤー
- `[確定]` アクション初心者から中級者以上まで
- `[方針]` 標準難易度では、操作を学べば突破できる分かりやすさを求める層
- `[方針]` 高難易度では、読み合いと最適な対処を磨きたい層

### 1.3 体験の柱

1. `[方針]` 敵の予兆を読み、パリィまたは回避し、大きな反撃へ転じる爽快感
2. `[方針]` 成功理由と失敗理由が理解でき、再挑戦ごとに上達を感じられる公平さ
3. `[方針]` 初期から豊富な操作が使え、入力に対して素早く格好良く反応する手触り
4. `[方針]` 小技、必殺技、装備スキルの組み替えによる戦い方の自由
5. `[方針]` 明るい冒険感とクールな剣戟演出を損なわないテンポ

### 1.4 非目標

- `[確定]` 極端な高難度を前提にプレイヤーを選別しない。
- `[方針]` 敵HPの多さだけで歯ごたえを作らない。
- `[確定]` 進行必須の追加移動能力を段階的に解放する構造にしない。
- `[方針]` 大量の説明、暗い悲劇、頻繁な会話停止を主役にしない。
- `[方針]` 広大な相互接続マップや大量のバックトラッキングを必須にしない。

## 2. コアゲームループ

1. ステージを進み、敵、NPC、オブジェクト、任意ルートを発見する。
2. 通常攻撃、パリィ、回避、必殺技を組み合わせて敵を倒す。
3. 敵撃破でポイントを得て、休憩所または拠点で小技スキルを解放、付け替えする。
4. 中ボスとボスで学んだ対処を試し、ボス撃破で新しい必殺技を得る。
5. 次のステージへ進み、機械文明と主人公の過去を断片的に知る。

- `[仮置き]` 死亡時に強化ポイントを失わない。再挑戦への心理的負担を抑える。
- `[確定]` HPが0になると直前の休憩所から復活する。
- `[確定]` ボス戦中の死亡はボスエリア付近から再開し、再戦までの移動を短くする。
- `[仮置き]` ボス再戦時は長い会話や演出をスキップ可能にする。

## 3. プレイヤーアクション

### 3.1 初期から使える基本操作

- `[確定]` 左右移動
- `[確定]` 標準の歩行速度は2026-10-16に採用した1.5倍比較版に合わせる。待機100ms・歩き8コマ×80msの絵を基準とし、現行床で実測約4.2057unit/s（UnityのmoveSpeed設定4.4019）を標準とする。
- `[確定]` ジャンプ
- `[確定]` 下入力とジャンプによる薄い床のすり抜け
- `[確定]` 4段の通常攻撃。最終段は高威力とする。
- `[確定]` 前方へ一定距離を移動し、無敵時間を持つダッシュ
- `[確定]` 敵の攻撃を弾いてひるませるパリィ
- `[確定]` 必殺ゲージを消費する必殺技
- `[確定]` 通常攻撃、ダッシュ、パリィ、必殺技は空中でも使用可能とする。
- `[確定]` パリィ成功後の追撃は初期能力とし、スキルツリーへ置かない。

### 3.2 操作上の仮置き

- `[仮置き]` 空中ダッシュは着地まで1回とし、着地で回数を回復する。
- `[仮置き]` 通常攻撃の先行入力を6F程度受け付け、入力抜けを抑える。
- `[仮置き]` 4段コンボは1から3段目をつなぎやすくし、4段目は高威力と引き換えに後隙を大きくする。途中で防御行動へ移る判断と、最終段まで出し切る判断の両方を成立させる。
- `[仮置き]` 被弾直後を除き、通常攻撃からダッシュまたはパリィへ限定的にキャンセルできるよう調整する。
- `[未決]` 4段通常攻撃の各段ダメージ、発生、持続、後隙、キャンセル受付の最終値
- `[未決]` 入力レイアウト、対応コントローラー、キーボード操作の標準割り当て

## 4. 戦闘リソース

### 4.1 HPと回復

- `[仮置き]` プレイヤーHP基準値は100とする。
- `[確定]` 回復アイテムの最大使用回数は3回とする。
- `[確定]` 休憩所で回復アイテムを補充する。
- `[仮置き]` スタンダードの1回当たり回復量は最大HPの40%とする。
- `[仮置き]` 回復中も短い移動を可能にし、完全停止による不快感を避ける。

### 4.2 休憩所

- `[確定]` 中継、セーブ、回復補充、スキル付け替えに使用する。
- `[仮置き]` 休憩で倒した通常敵を再配置するが、中ボスとボスは復活させない。
- `[仮置き]` オートセーブを休憩、ボス撃破、重要アイテム取得時に行う。

### 4.3 必殺ゲージ

- `[確定]` 最大値は100とする。
- `[確定]` 攻撃ヒット、パリィ成功、被ダメージで蓄積する。
- `[確定]` 高威力、大範囲の必殺技は60から80を消費する。
- `[確定]` 低威力、小回り型の必殺技は30から50を消費する。
- `[仮置き]` 通常攻撃1から3段目は各+2、4段目は+5、パリィ成功は+10、被ダメージは+8を基準にする。旧3段案と同じコンボ合計+11を保ち、4段化だけで必殺技の回転率が上がりすぎないようにする。
- `[仮置き]` 1回の多段攻撃によるゲージ獲得に上限を設け、密集敵での過剰回収を防ぐ。
- `[仮置き]` ゲージは通常戦闘間で持ち越し、死亡時は50を上限として保持する。

## 5. パリィ、回避、反撃

### 5.1 パリィ

- `[方針]` 狙って成功した実感を残しながら、スタンダードでは厳しすぎない受付にする。
- `[確定・2026-10-17]` モーションは「パリィ待機」「パリィ成功（軽）」「パリィ成功（重）」に分ける。入力で待機を開始し、有効な敵攻撃との接触で成功へ派生する。接触前に成功の弾き動作を再生しない。動画#69では軽を使用する。
- `[確定・2026-10-17]` 敵の攻撃ごとにパリィ可否と成功リアクションの軽・重を独立して設定する。軽・重はプレイヤーのリアクション（その場で弾く／大きく後ずさりながら弾く等）の区別で、通常成功／ジャスト成功という入力精度の区別とは別軸とする。パリィ不可攻撃は軽・重にかかわらず成功へ派生しない。複数攻撃の同tick成功では主対象の属性でリアクションを決め、追加ストックだけの接触で姿勢や向きを上書きしない。
- `[確定・2026-10-17]` 軽・重によって反撃の入力・対象選択・ストック・種類・威力・無敵・キャンセル条件を分岐させない。重のモーションで変位を加える際も、共通の反撃へ接続する。既存攻撃の初期属性は軽とし、重用の作画・変位は別途統合する。専用モーション未登録時は既存の成功モーションへ安全にフォールバックする。
- `[確定]` 連発を制限し、無計画な連打だけでは安定しないようにする。
- `[確定]` 正面かつ近距離の対象には軽い吸い付き補正を行う。
- `[確定]` 背面または高低差が大きい対象には吸い付かない。
- `[仮置き]` スタンダードの成功受付は発生後5Fから18Fとする。
- `[仮置き]` 空振り硬直26F、再使用クールダウン14Fとする。
- `[仮置き]` 成功時の敵ひるみ32F、プレイヤー硬直10F、ゲージ増加+10とする。

### 5.2 パリィ不可攻撃

- `[確定]` 種類を細分化しすぎず、基本対処をジャンプまたはダッシュに統一する。
- `[確定]` 通常攻撃と異なる強い予兆演出を使用する。
- `[確定]` 特殊対策スキルで対処できる場合は、大ダメージ、スタン、ゲージ増加など大きな報酬を与える。
- `[方針]` 専用対策スキルがなくても、基本操作で安全に回避できるようにする。

### 5.3 ダッシュ

- `[確定]` 前方へ一定距離を無敵状態で移動する。
- `[仮置き]` 全体20F、主移動12F、無敵4Fから12Fを初期検証値とする。
- `[方針]` 回避成功後に素早く反撃へ移れるようにし、回避だけで戦闘が途切れないようにする。

### 5.4 視認性

- `[確定]` 通常攻撃には予備動作と攻撃直前の光エフェクトを付ける。
- `[確定]` パリィ不可攻撃には、通常の光と混同しない形、色、音を組み合わせる。
- `[方針]` 色だけに依存せず、姿勢、輪郭、効果音でも区別可能にする。

## 7. 成長とビルド

### 7.1 基本方針

- `[確定]` 純粋なステータス強化は控えめにする。
- `[確定]` ボス撃破で必殺技を追加する。
- `[確定]` 敵撃破で得るポイントを使い、小技や補助アクションを解放する。
- `[確定]` 進行必須の追加アクションを設けず、戦闘の多様化と移動の快適化に使う。
- `[確定]` 主人公は最初から多くのことができ、不自由さを感じにくい設計にする。

### 7.2 スキルツリー

- `[確定]` 上位ノードの取得を前提とする分岐型ツリーにする。
- `[確定]` 一つの枝を一直線に深く進める取得方法も、同じ深さを横に広げる方法も成立させる。
- `[確定]` 解放済みスキルは休憩所で自由に付け替え、ビルドを試せるようにする。
- `[仮置き]` スキル解放は永続とし、装備枠4枠によって同時使用数を制限する。
- `[仮置き]` 通常雑魚1、変則雑魚2、小ボス級5、中ボス15、ボス30ポイントを基準報酬とする。
- `[仮置き]` ノードコストは浅層5、中層10、深層15を基準にする。
- `[方針]` 通常進行だけで各ステージ中に2から3個の新スキルを試せる獲得量にする。

### 7.3 現行スキル案

- コンボ短縮派生: 2段目から派生技へ移行する。
- 必殺キャンセル: 通常攻撃の終わり際を必殺技でキャンセルする。
- 弱点看破: 連続ヒット後、短時間だけ攻撃効率を上げる。
- 受け流し反射: パリィ成功時に飛び道具を敵へ反射する。
- 回避ゲージ回収: ジャスト回避成功時に必殺ゲージを微回収する。
- 空中受け身: 吹き飛び中に体勢を立て直す。
- 空中ダッシュ斬り: 空中ダッシュ中に突進斬りを出す。
