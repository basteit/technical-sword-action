# 11/22プロトタイプ計画（2026-11-15承認 / #109・#82）

体験目的: パリィから短い反撃へ素早く転じる戦闘を軸に、初見が自力で開始・終了・再挑戦できる2モード試遊版へ整える。

## 到達点と受入条件

1. 新規ドットの短い反撃、重パリィ、カジュアルな判定/範囲を最初に整え、左右・空中・壁際・複数対象・期限境界で操作と表示が復帰する。
2. 戦闘モードと最序盤ストーリーモードが開始→案内→プレイ→勝敗/区切り→再試行/戻るまで通る。新しい敵階級の戦闘お試し1=ザコ、2=強ザコ、3=小ボスを組み込む。
3. 物理ゲームパッド/キーボード・別PC・配布ZIPを同じビルドで確認し、重大な操作不能/進行不能を残さない。README・版番号・既知問題・素材/ライセンス・感想導線を合わせる。

11/22は短期試遊の到達点、11/29はEGG内容固定、12/5はEGG出展という既存計画を維持する。今回の承認はこの作業順と試遊の方向であり、試作値や未納素材の完成を承認したものではない。

敵仕様の正本は[敵5階級・攻撃属性](../enemy-tiers-20261115.md)。赤攻撃、重リアクション、Normal/Just、通常反撃、ボスQTEを別の意味として管理する。

成功時: 予兆を読んで守り、短い反撃で勝ちへ進み、もう一度試したくなる。
失敗時: 赤成功で反撃できない場合も含め理由が分かり、敗北からすぐ戻れる。受付切れや対象消失で操作をロックし続けない。

## 仮値と比較の方法

- 新反撃の出発点: 入力→命中8〜12F、全体24〜30F程度。停止は別に扱い、素材の接触姿勢と同期する。最終尺は未確定。
- カジュアル化の比較案: 現行受付0〜13F/距離2.5uに対し、0〜17F/3.0uを候補とする。高低差1.5u、Just0〜3Fは初回比較では維持する。承認済みの確定数値ではない。
- 一度に最大2軸。15分比較で成功/失敗理由、反撃につながらない状況、理由不明被弾、操作不能を記録する。連打だけで常時無敵にせず、壁越しや本来のパリィ不可を成功させない。
- 軽/重は敵の攻撃重量であり追加ボタンやJust必須にしない。通常の反撃可能攻撃は同じ短反撃を使い、赤は反撃受付を作らない。
- 戦闘は初回3〜5分、ストーリーは5〜8分を構成の仮目安にする。HPや会話で尺を水増ししない。

## 人が先に用意・確認するもの

- 新反撃: 構え→踏み込み→接触→振り抜き→復帰の主要姿勢をラフで先に渡す。接触コマ・足元・向きを明示し、既存32PPUの大きさと整合させる。11/16ラフ確認・11/17初回組み込みを仮目安にする。
- 重パリィ: 踏ん張り/押し返し等、軽との違いが分かる姿勢。円形衝撃波は基盤で先に試せる。原稿の受領と使用版・Unity検証を分けて記録する。
- ストーリー: 最序盤の本文と区間ラフ、話者/左右、終了地点。台本はユーザーが執筆・採用する。清書待ちで通し接続を止めない。
- 人の受入: 両入力各15分、初見の迷い、連続反撃の手触り、赤/重の区別。自動テストを人の合格へ読み替えない。
