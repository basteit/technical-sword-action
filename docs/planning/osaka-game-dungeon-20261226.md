# 大阪ゲームダンジョンまでの到達目安（2026-11-16 / #112）

体験目的: EGGで確かめた導入と戦闘を土台に、作れた範囲を無理なく一続きの試遊として楽しめるようにする。

## 受入条件（今回の計画・引継ぎ）

1. 「EGG導入＋中ボスまで」は到達の目安、「隠しボス」は間に合えば採用と記録し、全量達成を展示の必須条件にしない。
2. 優先順、未達時の安全な区切り、未決事項と本編要件との境界を明示する。
3. 現状・Git/素材/検証上の注意を新しいローカルチャットへ引き継ぎ、初回は読み取り確認だけで準備する。

## 最新の決定

- 大阪ゲームダンジョン展示までの実装目安は、EGGの導入部分に加えて、そこから続くステージの中ボスまで。
- 隠しボスも間に合えば実装する。
- かなり厳しい日程のため、あくまで目安であり、作れるところまで作る方針とする。中ボス未達を理由に、無理な新機能追加・未検証の接続・確認時間の全消費をしない。
- 仮置き: 対象は導入から続く最初のステージ（現行のステージ1想定）。具体的な道中、部屋数、敵、会話、所要時間、採用する中ボス/隠しボスの設計は未決。
- ステージ末ボス撃破、ステージ1全体、本編全3ステージの完成を今回の目安へ追加しない。本編の敵5階級・各ステージの中ボス/末尾ボス配置・隠しボスの分類は維持する。

## EGGから継承する部分

EGGは **主人公登場→順路を進みつつ動作チュートリアル→剣を拾う→戦闘チュートリアル→軽い戦闘** の冒頭導入。過去や現在の状況を具体的に明かさず、剣との会話で軽く触れる程度。冒頭/末尾の語りは未決のまま。[導入の正本](egg-introduction-20261116.md)。

大阪でも導入を作り直すことを前提にせず、EGGの感想と不具合を反映して先の区間へ延ばす。追加区間でどの情報を明かすかはユーザーの台本で決め、真相や新しい設定を勝手に書かない。

## 作業の優先順

1. **遊べる既存部分の安定と読みやすさ**: パリィ→短い反撃、予兆、入力復帰、壁際/空中/複数敵、勝敗・再試行・終了、物理パッド/別PCの確認。
2. **導入の先の道中**: 短い区間を既存素材・敵・地形で一つずつ完成させる。未完成の長いマップを一括でつなげない。
3. **中ボスまでの接続を目指す**: 既存部品を再利用して必要な攻撃・予兆・後隙・対処・HPバー・撃破・再挑戦を確認する。#53は候補だが、旧着手条件と新5階級の役割を照合してから採用する。
4. **隠しボス（任意）**: 上記と品質確認の余裕がある場合だけ採用する。間に合わなければ展示範囲から外して後続へ残す。

成功時: 学んだ操作を道中と中ボスで試し、続きがあると感じて終えられる。
失敗時: 中ボスに届かなくても、完成した区間に明確な終了・再試行があり、未完成箇所で進行不能にならない。

## 隠しボスを採用するときの注意

- 隠しボスはボス階級であり、独立した第6階級ではない。
- 現行のボス定義には「特殊攻撃のパリィ成功後の連打QTE」がある。採用時はその未決事項と制作/実装/確認コストも見積もる。QTEを勝手に必須の大阪作業へ昇格させず、同時にボス要件を黙って削らない。
- QTE、素材、攻撃、退出/復旧が間に合わない場合は隠しボスを見送るか、明示的な仕様変更の合意へ戻る。名前だけボスにした未検証の敵を展示しない。

## 間に合わない場合

- EGG改善版だけ、導入＋完成した道中まで、中ボスまで、のいずれでも「実際に安全に遊べる終点」を採用できる。
- 中ボス/隠しボス、新規外見、追加表情、背景の細部、新曲、PV等を縮小・延期し、実装済みの安定と確認を優先する。
- 未完成の部屋・敵・会話・メニュー項目は試遊から外す。途中地点にも今回の終了案内と再試行/戻るを置く。
- 未達と採用範囲をビルド番号・README・感想フォームの案内へ反映する。仮素材や部分実装を本編全量の完成と呼ばない。
