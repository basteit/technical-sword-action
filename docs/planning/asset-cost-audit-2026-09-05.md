# 素材量・制作工数の監査（2026-09-05）

## 判定と前提

数量の上限と再利用方針は整理されている。ただし、正式承認済み素材数、作画担当の稼働、納期、制作実績が未記録のため、9月20日の全素材完成と本編1年完成を現状では裏付けられない。

- 主担当は週20〜30時間。サウンド担当は継続参加見込みだが週稼働は不明。イラスト担当は外部の友人で、稼働・対応可能な素材・納期は未確認。
- 主担当の稼働枠は9月5日から20日まで約43〜64時間、30日まで約71〜107時間。実装、調整、素材受入、テストを含む総枠であり、作画へ全量を使える時間ではない。
- 本資料の人時は市場価格や業界平均ではなく、実測前の計画用推計。担当者の経験、画風、修正量、既存素材の利用範囲で変わる。
- 画像は目視評価していない。ファイルの存在や試作用Clip数から、正式素材の完成率・品質を判定していない。外部保管済み素材は受領確認後に加える。

音の推計ではBGMを仮に2〜3分のループ4曲とする。曲尺は現行仕様で未定であり、発注時に合意する。追加BGM、ボイス、推奨の敵・任意ルート等はこの表に含めない。

9月末の制作枠は、主人公110〜280人時＋仮敵の可読化・基本VFX16〜40人時＝**作画のみ126〜320人時**、戦闘音は**16〜40人時**を初期値とする。本編表の内数であり、全編見積もりへ再加算しない。初稿は陰影・中割りの描き込みを簡略化できるが、24モーションの現行条件は維持する。

ここにAI、行動制御、素材のUnity接続、判定調整、レビュー対応、ゲーム内テスト等の主担当実装人時は含めない。これらは開発側に一度だけ計上する。制作側修正と開発側確認は別作業として記録し、同じ工数を二重計上しない。

仮にアート担当が週10時間なら、本編アート表を一人で新規制作する単純換算は約87〜198週となる。これは納期予測ではないが、参加人数だけでは1年計画を支えられないことを示す。実際の承認済み素材、担当範囲、稼働、再利用率を先に測る必要がある。

## 最初の承認サンプルと判断ゲート

1. 担当者ごとに週稼働、制作可能範囲、提出予定日、確認担当者を記録する。イラスト担当の本編全素材対応を前提にしない。
2. 主人公のモデル、色票、剣の長さ、非対称部分の左右反転可否を共有する。
3. **Idle4F＋Attack_1 8F＋ParrySuccess4Fの計16描画フレーム**を代表サンプルにする。原稿、PNG、ゲーム内確認、修正1回、承認までを一単位として測る。
4. デザイン、作画、書出し、制作側修正、開発側統合、確認の実時間と待ち時間を分ける。描画フレーム数と60Hz戦闘tickを混同しない。
5. 通常動作・攻撃・特殊ごとの実測単価×未完成枚数で再見積もりする。追加修正予備20〜30%を置く場合は、全体計画の予備との重複を除く。
6. 各カテゴリの残人時÷担当者の合意済み週稼働に、納品待ち・統合待ちを加え、9月20日の統合に間に合うか判定する。間に合わない場合は、未達見込みと次ゲート日を記録する。

サンプルの合格条件は、足元の揺れ1px以内、右・左向きで崩れない、通常攻撃の見た目と判定差2F以内、参照切れなし、原稿から再書出し可能、当事者が見た目を承認し制作時間を記録済みであること。ファイルを受け取っただけでは承認済みにしない。

本編量産の前には、通常敵1種の全動作、森の代表1画面分のタイル・小物、代表ボス攻撃1つ、探索BGM1ループも同じ工程で測る。ボスと背景の単価を主人公サンプルだけから推定しない。

## 発注・受領時に埋める不足

- 素材台帳：素材ID、数量、担当、状態、基準仕様の版、原稿・納品先、予定日、承認日、実時間。外部保管の完成物もここへ集約する。
- 作画仕様：敵カテゴリ別キャンバス、Pivot、色票、動作とキーPose、背景の部品点数。仕様書でも敵画像サイズは未決。
- 音仕様：Event ID、発火条件、尺、Variation数、ループ点、納品形式、ゲーム内音量の調整担当。
- 依頼条件：有償・無償、担当範囲、修正回数、受入条件、納期変更時の連絡、原稿利用・改変・商用利用・クレジット等の合意を共有メモに残す。
- 規格の基準点：主人公ガイドはAnimationEventが戦闘処理本体と説明する一方、仕様書「18.2」はActionデータ移行後を区別している。制作Briefには対象コミットとHit・Cancel・Endの基準を明記する。

監査時点では`docs/production/`と素材別納期台帳は見当たらず、仕様書画像manifestは空だった。これは外部に素材がないことを意味しない。主人公ガイドの「14接続・10Clipのみ」も文書上の説明であり、現在の実装完了率とは分けて更新する。
