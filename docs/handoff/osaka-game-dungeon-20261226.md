## 5. 敵5階級と攻撃の最新仕様（主に文書のみ）

| 階級 | 上位へ累積する特徴 |
| --- | --- |
| ザコ | 基本の攻防・通常反撃 |
| 強ザコ | 赤攻撃を追加：パリィ可、当該成功から通常反撃不可 |
| 小ボス | 重パリィ攻撃を追加 |
| 中ボス | 敵の体力バーを追加 |
| ボス | 特殊攻撃のパリィ成功からボタン連打QTEを追加 |

- 隠しボスもボス階級。各ステージ中ボス1体＋末尾ボス1体、一部ステージに隠しボスを追加。正確な隠しボスの配置/数/人物は未決。
- 軽/重は敵の攻撃重量、Normal/Justは入力精度。反撃可否とも別軸。重だから旧キックへ自動分岐させない。
- 旧「赤=パリィ不可」は新仕様で廃止。パリィ可否と反撃受付の生成を分離する必要がある。赤で通常反撃用の受付/期限を生成・更新しない案。他個体の正当な受付まで消さない。
- ザコは到達水準で反撃ほぼ一撃、強ザコ/小ボスは反撃1回に耐えるHPを目安に個別調整。階級から即死を強制せず、HPだけで長期戦にしない。
- 戦闘お試しの新対応は1=ザコ、2=強ザコ、3=小ボス。数字キー割当/自動Wave/個体数はまだ実装・確定していない。
- ボスQTEのボタン、時間、回数、成否結果、無敵/時間制御、連打アシスト等は未決。大阪で任意の隠しボスを採用するならこのコストも再見積もる。間に合わなければ隠しボスを見送る。
- 正本: [敵仕様](../enemy-tiers-20261115.md)、Issue #109。新5階級/赤の新ルール/ボスQTEがゲームへ実装済みだと思わない。
