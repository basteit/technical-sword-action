# プロトタイプ会話（#51）

## 体験目的

既存の調べる場所から、立ち絵と会話ボックスが自然に現れる短い会話を試し、後から受領する素材をコード変更なしで適用できるようにする。

2026-10-25のユーザー依頼により、旧計画の「戦闘プロトタイプ後」から今回のプロトタイプへの追加へ変更する。戦闘プロトタイプ全体の受入完了を意味しない。

## 受入条件（実装前）

1. `PrototypeCombatValidation` の既存 `InteractCounter` でE／文脈Bを押すと、回数加算の代わりに会話が始まり、最初の左キャラが `Test` と表示する。
2. ボックスは不透明度0→1でフェードインし、立ち絵は最大2人。主人公側は左、その他は右へ置く。各側の初登場・別キャラへの交代だけ、その側の画面外方向からスライドし、同じ話者の次の台詞では繰り返さない。ボックスと立ち絵のSpriteは設定から交換できる。
3. 会話中の全ゲームプレイ入力・Pauseを抑止し、終了入力の解放後に復帰する。Skip、被弾、死亡、リセット、Disableでも表示とロックを残さない。既存の4段攻撃・パリィ反撃へ退行を出さない。

成功時は調べる入力から会話が滑らかに開き、話者の位置が一貫して読める。開始条件を満たさない場合や中断時は半端な表示を残さず、攻撃・ジャンプの誤発火を起こさない。

## 決定と仮置き

- ユーザー決定: ボックス表示、最大2人、主人公側が左、その他が右、新登場時の外側からのスライド、左の `Test`、既存インタラクト回数加算との置換。
- 仮置き: フェード0.35秒、スライド0.3秒・80基準px、非話者の明度65%。非スケールUI時間で進め、戦闘時計と `Time.timeScale` は変更しない。
- 仮置き: サンプルは左 `Test` →右 `Test` →左 `Test` の3行。左右登場と同一キャラの再発言を確認するための台詞で、物語の確定稿ではない。
- 素材未受領: ボックスは単色、立ち絵はUI図形の仮シルエット。ユーザー原稿・完成素材として登録しない。受領後に交換し、原稿登録と適用検証を分ける。
- 対象外: 分岐、好感度、既読保存、ボイス制作、タイプライター表示、最終装飾。
