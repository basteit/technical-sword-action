# プロトタイプの移動感調整（#84 / #34）

体験目的: ジャンプ頂点のがたつきと地上ダッシュ後の引っ掛かりを減らし、移動と戦闘の確認に集中できるプロトタイプにする。

## 着手時の受入条件

1. ジャンプの頂点は受領原稿の5→6コマを一方向にゆっくり表示する。高さ・重力・可変ジャンプ・床抜け・空中行動の所有権を変えず、30/60/120fps、Pause/Hitstop/Resetで整合する。
2. 通常移動を直前より速くし、地上Dashの主移動12F・約3.6unit・無敵12Fは維持したまま後隙だけ短縮する。押し続け移動へ自然につなぎ、空中Dash20F・着地まで1回と中断時の安全性を保持する。
3. PrototypeCombatValidationから会話テストの箱・専用UIを外し、再生成時にも自動配置しない。共通の会話機能・原稿・Prefab・会話データと自動回帰テストは残す。新規退行がないことを関連テストと実画面で確認し、人による操作感の受入は別に残す。

成功時: 頂点の姿勢が読み取れ、ダッシュから走りへ少ない待ちで戻れる。失敗時: Dash無敵の終了や再使用待ちが診断表示で説明でき、見た目の調整がジャンプの高さや攻撃・パリィの条件を密かに変えない。

## 作業単位と仮置き値

- #84の移動素材接続・#34の操作感調整に対する同じチャット内の追調整とする。会話テスト撤去はユーザーが明示的に同時指定したスコープ縮小で、#51/#49の会話機能そのものの廃止ではない。
- 調整を「頂点表示」「会話テスト配置の撤去」「通常移動と地上Dash」の意図別に分ける。1段階で変える操作感の軸は2つ以下とする。
- `[仮置き]` 頂点の切り替え間隔3→6F、表示帯域は鉛直速度±2→±4unit/s。5↔6の反復はやめ、5→6→落下7とする。物理滞空を追加しない。
- `[仮置き]` PrototypeCombatValidationのmoveSpeedは4.4019→5.28228（+20%）。待機100ms・歩き8コマ×80ms、撮影用の旧標準速度は保持する。
- `[仮置き]` 地上Dashは12F主移動+2F後隙=14Fへ短縮。再使用待ちは終了後14Fを維持するため開始から28F。空中Dashは従来の20F/開始から34Fのまま。新しい地上設定はMotorの任意オーバーライドとし、未指定の既存Scene/動画は旧動作を維持する。
- 通常完了した地上Dashだけ、入力があれば同tick末尾で通常移動速度へ引き継ぐ。Hit/Dead/Disable/Reset/明示キャンセルでは引き継がない。
- 会話の自動テストは必要な場合だけ実行中に専用fixtureを作り、保存Sceneや共有素材を変更しない。

## 検証結果

- Compile Error0 / Warning0、全EditMode 343/343、関連PlayMode 113/113（移動24・会話19・SE38・近距離パリィ25・素材統合7）。
- 頂点5→6の順序と各コマ6F以上の表示、速度比1.20、地上Dash14F/終了時の移動引き継ぎ/残りCD14F、空中Dash20Fと着地途中での長さ維持、Hit/Dead/Reset/Disableでの引き継ぎなし、旧会話テスト位置での共有B→Dashを確認した。
- 会話テスト用配置は実行時fixtureへ移し、会話の19回帰とInteractのSEテストを維持した。共有Prefab・会話データ・ユーザー素材は変更していない。
- 全体回帰と実画面は確認中。直前の全PlayModeは928件中915合格・既存13失敗であり、全体合格とは扱わない。既存失敗の内訳と比較証跡は[前回の接続記録](prototype-mobility-and-proximity-parry.md)を参照。
