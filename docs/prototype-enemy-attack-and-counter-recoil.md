# 敵の攻撃継続と生存時の反撃後退（#34 / #52）

体験目的: 敵の振りかぶりを読んで弾く価値を保ち、反撃後の姿勢で生存と撃破を見分けられるようにする。

## 受入条件

1. 反撃で生き残った敵（無限HPダミーを含む）は、既存の斜めのやられ絵を固定し、主人公側を向いたまま後ろへ滑る。跳ね上げ・回転・位置の巻き戻しはしない。横距離と時間は選択中の反撃設定を維持し、壁では止まり、足場を外れたら落下する。
2. プロトタイプの敵は予備動作開始から攻撃判定終了まで、斬撃・必殺技などの非致死被弾で姿勢・向き・判定・攻撃役を中断されない。ダメージ・命中演出は成立する。成功パリィと撃破は引き続き割り込み、攻撃後の隙には従来どおりひるませられる。
3. 左右、停止中、壁、リセット、通常敵とダミー、F11/F12の比較切替を確認する。致死反撃の吹っ飛び・フェード、通常の命中演出、撮影用の素材と設定を維持する。

成功時はパリィが相手の攻撃を止めることと、反撃で押し返すことが読める。斬撃で押し切ろうとした場合も敵の予兆が被弾絵に隠れず、攻撃が来る理由を判断できる。今回は進行中のプロトタイプ調整PRへの追補とし、2軸を分けてコミットする。

## 実装・確認方法

- F4で無限HPダミーを出し、攻撃をK / 右クリックでパリィしてからJ / 左クリックで反撃。生存時だけ `EnemySample_chance_01` を後退終了まで表示する。通常設定は1.6unit・18F、比較設定は3.2unit・22Fで、選択中の横移動を流用する。斜めは絵の姿勢で、回転や上向き移動は加えない。F1の撃破時は引き続き既存の軌道と消滅を使う。
- 予備動作中に斬撃を当てても、ダメージと短いヒットストップのあと、同じ予兆から同じ攻撃判定へ進む。攻撃判定が終わった隙では通常の被弾姿勢に切り替わる。デバッグ表示で `Armor`、`Reaction AttackArmor`、`Counter retreat` と移動量を確認できる。
- 攻撃中の耐性は通常ザコの2設定と強ザコの攻撃別設定に接続。未設定の別Sceneや撮影素材は変更しない。生存時の後退は `CounterCinematic` と `CounterLaunch_ReferenceTrial` の `groundedRetreatOnSurvival` で有効化し、F12で撃破・パリィやられを比較しても有効。威力・時刻・カメラ・SEは維持する。

## 確認結果

- 攻撃継続の関連PlayMode 50/50、後退の関連PlayMode 14/14。左右・描画30/60/120fps・壁・足場・Pause/Hitstop・非致死と撃破・パリィでの割込みを確認。
- Game ViewでF4のダミーに実パリィから1Hit。後退8Fで横1.32565unit、高さ変化0、`EnemySample_chance_01` を確認。Console Error 0 / Warning 0。プレイテストの手触り判断と配布ビルドは別途。
- コンパイルとアセット検証に合格。維持対象全体はEditMode 337/337・PlayMode 690/690、Skip 0。CLIの待機上限後にUnityが完了したXMLを確認し、テスト選択136項目も合格。最後は未保存変更のないEditMode。保護対象18ファイルのハッシュは不変。
