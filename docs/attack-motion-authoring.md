# 攻撃移動の設定

Hierarchy の Player を選択し、Player Attack 2D を開く。

## 基本設定

- Attack Steps の Element 0〜3 が攻撃1〜4段目。
- Ground Motion Distance: 向きに対する移動距離。正は前進、負は後退。
- Ground Motion Duration: 等速移動する時間（秒）。
- Air Attack Movement / Air Move Speed Multiplier: 空中攻撃中の通常移動速度に対する倍率。初期値0.35。

PlayMode中の変更は停止時に戻るため、保存する調整はEditModeで行う。

## 複雑な移動

各段階の Use Ground Motion Curve を有効にすると、距離・時間の等速設定に代わって Ground Motion Curve を使用する。

- 横軸: その段階が始まってからの秒数。
- 縦軸: 開始位置からの累積移動距離（ワールド単位、キャラクターの向き基準）。
- 最初のキーは時間0、距離0を推奨。
- 平坦な区間は停止、上昇区間は前進、下降区間は後退。
- 最後のキー以降は移動しない。攻撃終了・キャンセルでも移動を終了する。
- 接線をLinearにすると区間ごとの等速、滑らかにすると加減速になる。自動接線のオーバーシュートには注意する。

例: (0,0) → (0.10,0) → (0.20,0.20) → (0.30,0.20) → (0.40,0.10)。
0.10秒待機、0.20前進、0.10秒停止、0.10後退を表す。
回数専用の設定は不要で、必要な数だけキーを追加する。

物理速度にカーブの差分を適用するため、壁に阻まれた分を後から取り戻すワープは行わない。
空中ではこの地上移動カーブを適用せず、移動入力を倍率で抑える。

現在のカーブ時間は戦闘時計の経過秒であり、Animatorの再生速度・遷移ブレンドを直接参照しない。
クリップの尺・再生速度を変えた場合はキーの時間も調整する。
モーションが確定した段階では、攻撃定義アセットにクリップと移動カーブをまとめ、フレーム単位のプレビューで同時に編集できる仕組みが望ましい。
プレイヤー本体のTransformをAnimation Clipから直接動かすと物理移動と競合するため、実際の移動はMotorが担当する。
