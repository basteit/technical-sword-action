# 敵の攻撃ピークに合わせるパリィ試用（#33）

> 本文は初回40F・背景20%・表示待ち15F版の検証履歴。追加依頼による最新調整は[36F・背景30%・8F待ち版](prototype-parry-impact-sync-retune.md)を優先する。

## 体験と今回の決定

「成功した瞬間に敵がやられへ飛ぶ」表示をやめ、敵の攻撃を受け止め、弾ききる一連の動きを見せる。強い暗転をパリィごとに繰り返さず、閃光・有限の屈折・停止を主役にする。

ユーザーは1/10速度の確認動画の暗転開始〜終了に相当する停止を希望し、約0.67秒の意味であることを確認済み。通常・Justとも40Fを試用する。最終的な操作感の受入は別に行う。

対象は本編プロトタイプの現行軽パリィ。既存完成動画のScene・Library・Clipと受領原稿は更新しない。主人公の新しい振りかぶり原稿は未受領で、既存の準備2コマを時間配分し直して仮表示する。作画を追加・完成させたとは扱わない。

受入条件は、①成功判定を維持して敵のピークへ表示を同期、②弾き後によろめきへ移行、③弱い演出でも成功を確認でき、中断後に表示・停止・入力予約を残さない、の3点。

## 時間の分離

```text
成功判定（敵の攻撃は無効、ストック取得）
    → 既存の準備コマ＋敵の攻撃継続表示
    → 敵のピークと主人公の接触姿勢・閃光・40F停止・歪みが同期
    → 弾きの振り抜き8F
    → 敵のやられ表示／予約した反撃
```

- 判定の成功タイミング・受付・Just判定・HP・威力・ゲージのルールは変更しない。表示待ちの敵が新しく攻撃判定を出すこともない。
- 敵ごとの `VideoArtLibrary.Motion` に `hasParryImpact / parryImpactFrame` を持たせる。現行汎用雑魚は `Enemy_Attack` の元12F＝`EnemySample_attack_14`（口を閉じる絵）を登録。
- 選択中の攻撃のActive・Recovery・現在経過から、ピークまでの残りtickを計算する。画像から口を認識する仕組みではない。新しい敵素材・攻撃へは意味のあるピーク位置を登録する。
- 現行の動画準拠通常ザコでは、成功から15Fでピークへ到達。主人公の成功前2コマは10F＋5Fとして表示される。敵は攻撃12→13→14枚目を表示してから止まる。
- 同期情報のない仮敵・攻撃は成功時の接触へフォールバックする。未提出の重パリィを完成表示へ昇格させない。
- 表示同期と弾き終わりまでは成功状態を保持。Attackは1入力1件の予約として保持し、弾き後に対象・ストック・開始条件を再確認する。無入力で反撃せず、予約のために先にストックを消費しない。
- 反撃受付180tickの論理開始は従来どおり成功時点。40F停止では残り時間が進まないが、準備15Fと弾き8Fは180tick内で進む。表示上のやられ開始後の残りは約157tick（2.62秒）。やられ開始から3秒に延長する調整は今回行っていない。

## 試用値と戻し方

- `CounterCinematicProfile.synchronizedParryImpact=true` で新方式。使用中プロファイルは `CounterLaunch_ReferenceTrial.asset`、元反撃用の `CounterCinematic.asset` にも同じパリィ設定を持たせる。
- `parryTrialHitstopFrames=40`。通常成功・Just共通。反撃の16F停止と既存暗転・カメラ・吹っ飛びは変更しない。
- 背景減光上限20%、入り2F・保持2F・戻り0.2秒の1峰のカーブ。全身の補助光は従来の40%。同じカメラの再減光を0.4秒抑制する。
- 歪みは既存の作画閃光座標を中心とし、0.24→0.4秒、基準変位22→32px、強度倍率1.55（設定0.65で上限1）。1カメラにつき最新1波で、波や変位を加算しない。
- F7のFlash 0/50/100%で減光・補助光を調整する。F8/VFXと `FeedbackSettings.parryShockwave=0` は歪みの制御。いずれも停止40Fや同期先を変更しない。
- 旧方式との比較は、リセットしてから `synchronizedParryImpact=false`。敵は即やられへ戻り、停止は元の通常9F/Just10F、背景99%・4F、歪み0.24秒・22pxへ復帰する。PlayMode中の無リセット切替を推奨しない。
- 所有者つきの敵表示上書き、入力予約、停止、減光はReset・対象消失・被弾・死亡・Disable・Scene変更で解除し、Pause中は進めない。Flashを0にした後、値だけ戻して古い明滅を再開しない。

## 人間による確認

- 40F停止が、単体・複数敵・連続成功で重みとテンポを両立するか。
- 準備2コマの仮引き伸ばしが許容できるか。新しい振りかぶり素材の追加後は、この時間区間を新コマへ置き換える。
- 暗転軽減後も成功を認識でき、他敵の予兆・足場が読めるか。F7/F8の0/50/100%でも確認する。
- 反撃予約が早すぎる自動発動に感じられないか、敵ごとのピーク位置・弾き後のやられ開始が自然か。
- 実物キーボード・パッド各15分、低スペックDevelopment/Release Buildの性能確認。新ZIPはまだ作成しない。
