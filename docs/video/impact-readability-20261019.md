# パリィの鋭さと電撃カウンターの接触を整理（2026-10-19）

「鋭いパリィ、重い反撃」を基本に、反撃の雷を強め、人物と接触の見やすさを保つ演出版。主人公の原稿・共用PNG・モーションの時間配分は変更しない。

## 調整内容

- 電撃の衝撃輪を主人公と敵より後ろへ配置する。中心の明るさを下げ、接触を囲む枝状の放電を追加。放電の中心は空け、足と敵を見せる。青紫の縁・水色・短い白の芯を32PPU/Pointのドットで描く。
- 原画に描き込まれた軌跡を残し、命中tickとそのヒットストップ中だけ敵を主人公より手前へ表示する。停止解除・リセット・Disableで元の描画順へ戻す。本編の標準sortingOrder=0にも衝撃波が重ならないよう、外周VFXの背景順は既定-1とする。
- 発光補助は命中直後の2動画Fへ集中し、外周のドットはその後も残す。命中時の白Flashも短くし、方向付きの揺れを大きな一撃と反動へ寄せる。8Fヒットストップは維持する。
- パリィの接点へ短い暖色の火花を追加し、従来の大きな十字を0.75倍へ整理。揺れを6動画Fの鋭い反応へ調整。敵のルートや当たり判定を動かさず、上体だけが3戦闘tickで後ろへ小さく揺れ、12tickで収まる。停止中の接触姿勢は維持する。
- 吹っ飛びが命中tick内に1段進んでいたため、開始を次の進行tickへ修正。命中時の絵だけでなく位置と角度も保持し、ヒットストップ中に敵が足から離れないようにする。
- 瞳の残光は寿命と不透明度を下げ、足の電気が主役となる強弱へ調整。暗転強度と主人公の明るさ補助は維持する。

`VideoVfxRenderer.ReadableImpacts` で新しいVFX/揺れ/目の残光と従来値を比較できる。敵の接触保持修正は比較に関係なく適用する。`HybridGlow=false` では追加放電も純ドットとなる。生成ドットはプールとキャッシュを使い、Resetで非表示、Scene破棄でTexture/Spriteも解放する。

既存 `Emit` / `AdvanceVisuals` / `ResetEffects` のAPIを維持する。本編が使用する最小3モーションのSnapshotでも、追加放電を生成できる。原稿やSnapshotのコピーを増やさず、撮影/Studio/本編の共用箇所を回帰に含める。
