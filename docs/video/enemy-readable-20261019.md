# 敵の攻撃モーションをゆっくり見せる（2026-10-19）

敵の攻撃が性急という指摘に合わせ、主2段テイクでは提出原稿の溜め・口元の発光・突き出す姿勢を見せてからパリィする。接触までを従来の0.5秒から設定1.6秒へ延長し、全体は **5.133333秒**。原稿の画素/表示時間と主人公/VFX素材を保持する。

## 接続

- 敵原稿1〜12枚目を接触前の96tick（1.6秒）、13〜14枚目を攻撃後の24tick（0.4秒）へ接続。100msは6tick、200msは12tickとし、原稿の表示時間に一致させた。
- 主2段の背後接近で、Libraryの96tickを撮影用AIの予兆時間へ渡す。元の値を保存し、Resetで移動速度/射程とともに復元する。本編の敵定義/配置は変更しない。
- 敵の予兆アニメは、そのAIの予兆時間へ再生倍率を合わせる。従来の4段比較/攻防切替/練習の発生時刻を一律に延長しない。今回これらの全回帰は再実行していない。
- パリィ待機は接触の約9tick前に入力する既存方式。発光中に成功反応へ切り替えず、12枚目の突き出す姿勢を見せた後に、同じEnemy_Bへパリィする。
- 攻撃後の表示保持は固定16tickからLibraryの長さを参照する方式へ変更。予兆の再生倍率はIdle/Reset/Disableで残さない。
