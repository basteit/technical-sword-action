## 読み取った演出

4.0秒付近の金色の横線/十字は接触前から出る予兆。接触の光と混同しない。4.3秒付近は武器の接点に短い白金色のピークがあり、姿勢とカメラの変化が同時に始まる。4.5秒以後の大きい紫の方向線/光には後続のアシスト攻撃が含まれるため、その長いピークを今回の軽い弾き全体へコピーしない。接触の短い強さ、武器が離れる方向、敵の反動、速い画面復帰を今回のドット演出へ組み直す。

前版は主人公の頭/腰が深く後方へ沈んでから前上へ返る。判定は弾き成功なのに、接触停止の絵が被弾/押し込みのようになり、足場・刀・敵の反応の意味がずれていた。強さを主人公の大きなのけぞりに集める方式を改める。

## 軽い/重いパリィの区別

| 要素 | 今回の軽い弾き | 重いパリィの作画/演出案（今回は未制作） |
|---|---|---|
| 主人公の足場 | 両足を保つ。短い膝/腰の受け止め | 膝/腰を深く落とし、必要なら後ろ脚を踏み直す |
| 刀と上体 | 手/肘で短く外上へ弾き、胸の向きを少し回す | 両腕/胴体で強い負荷を受け、押し返しを大きくする |
| 成功の見せ場 | 接触→瞬時に武器を分離→短い戻り | 接触/負荷を長めに保持→重い反動→戻り |
| 敵 | 武器が直後に跳ね上がり、上体が後ろへ反る | 武器/全身のさらに大きい反動、必要なら後退 |
| VFX | 細い斜線・小さい接触核・上へ飛ぶ火花。輪を使わない | 太い衝撃線/広い火花・圧力の輪などを別の形として検討 |
| 画面 | 一度の強い反動と短い揺り返し、2描画Fだけの暗いアクセント | 長めで低い揺り返し。負荷の保持と復帰を別調整 |
| 停止 | 現行Normal/Just 2/3F、最後の蹴りは8F | Lightより長い停止を将来の重い攻撃と合わせて決める |

Normal/Justは入力の成功精度、Light/Heavyは攻撃の重さの区別。今回のJust成功でも軽い弾きの姿勢を使う。重いパリィの攻撃元属性・ロック時間・後退/壁判定・専用作画は今回の動画の受入条件へ追加しない。

## 今回の実装

- `ParryDeflect`は6コマ/19Fを保持し、成功は3枚目から。1/2枚目は接触の準備。3枚目は安定した腰/足と短い刀の押し出し、4枚目は外上へ跳ね上げる振り、5枚目は振り終わり、6枚目は戻りの入口。成功後の大きい後退を取り除いた。
- 接触がAnimator更新後の物理で発生しても、その場で3枚目を表示する。成功後は同じ戦闘時計でSpriteを進め、Hitstop中に構えの絵が残らない。ゲームの成功/振り向き/対象/ひるみ/無敵の契約は維持。
- VFXの中心を両Actorの中点から、刀の接触キー(51,18)pxへ移した（pivot(32,26上端基準)、32PPU）。主人公の顔/胴体へ光の中心を置かない。
- 敵の武器は接触の最初のコマで刀の接点へ届き、次で上へ大きく離れる。足裏/腰の基準を維持し、反撃命中までのけぞりを保持する。
- VFXは大きい円から、細い斜線/小さい白い核/上外へ飛ぶ7本の火花へ変更。大きさ1.1。ドット＋短い加算発光を採用し、純ドット比較も保持。
- カメラは7/60秒、0.135unit、1.25周期の反動。以前の3.5周期の細かい揺れを減らし、一度の衝突と戻りへまとめる。白背景には黒12%→6%→0の短い2描画Fアクセント（60fps）を入れる。蹴りのFlashは白へ戻し、色を残さない。
- 地上の無入力時は自由な復帰、入力があれば次の行動へ直接進む。軽い弾きの戻りに追加のロックは付けない。
