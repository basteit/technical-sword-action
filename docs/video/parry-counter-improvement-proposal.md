# パリィと反撃の改善案（2026-10-12）

「スロー明けに素早く振り抜く」「パリィをもう少し派手にする」という相談に対する推奨案。ここに記載する速度とVFXの追加変更は未採用。今回実装した敵ののけぞり・スロー中の薄い暗転と区別する。

## 反撃：タメと振り抜きを分ける

現状は回し蹴り18〜28Fの全区間を0.25倍にし、命中時にスローを解除している。足を前に伸ばす24〜28Fも遅いため、タメからの加速が見えにくい。

| 区間 | 現状 | 推奨案 |
|---|---|---|
| 18〜24F | 0.25倍、0.4秒 | 0.15倍、約0.667秒。引いた脚と重心のタメを見せる |
| 24〜28F | 0.25倍、約0.267秒 | 通常速度、約0.067秒で振り抜く |
| 28F命中 | スロー解除、8F停止 | 既に通常速度へ戻った状態で命中し、8F停止へ移る |
| 明るさ | 命中から6描画Fで戻す | スロー解除時から3描画Fほどで戻し、命中前に明るい画面へ移る |

タメの実時間0.5〜1秒を保ち、解除から命中までの動きが約6.7倍に加速して見える。4段動画は現状4.85秒から約4.917秒、2段は3.833秒から約3.9秒となる見込み。命中時刻、対象固定、無敵のAction範囲、敵のひるみ保持は維持する。

振り抜きには短い残像を1〜2枚と、足先をつなぐ1コマの軌跡を加える。清書では24Fと26Fの姿勢から28Fの接触までを一つの振りとして読める形にする。開始時だけの残像を増やすより、スロー解除直後へ集中させる。

実装する場合は解除時刻も戦闘tickのEventにする。描画fpsで判断せず、Pause/Hitstop/30・60・120fps、中断・対象消失、40回再実行を再確認する。

## パリィ：剣を弾く方向と短いピークを強調する

現在の丸い輪を中心とする描画に、剣から飛び抜ける斜めの白い線を主役として加える。中心の白いFlashは1〜2描画F、金色の火花は6〜10描画Fで消す。全体の発光補助は採用済みの混合方式を使う。

撮影時のパリィVFXの大きさは0.75から1.0〜1.05を試す。約1.3〜1.4倍のサイズで、足・顔・敵の剣が読める範囲へ広げる。敵の剣が跳ね上がる姿勢と、上半身が後ろへ反る動きに線と火花を同期する。

停止は現行の通常/Just Parry 2/3Fから試す。見た目のピークを強めて短く抜ける構成とし、蹴りの大きな円状衝撃波と8F停止には別の強さを持たせる。成功点は鋭い線と火花、最後の撃破は大きな輪、という形の違いで無音でも読み分けられるようにする。

参照は受領した儀玄の映像の、短い明るいピーク、金色の方向線、黒い残像、反撃時の加速。粒子を長時間増やすより、弾いた瞬間に密度と輝度を集める案を推奨する。

## 今回実装した変更

- 敵の弾かれ4ポーズに、接触→後方へ反る→少し戻る→ひるみ保持の姿勢を加えた。足元と腰の下のドットは保持する。
- スロー中に不透明度14%の黒を重ね、5描画F相当で入り、スロー終了後は6描画F相当で戻す。実時間のフェードはPause中に止まる。
- 中断・対象消失・Disable・Scene変更・リセット時の暗転解除を検証する。
