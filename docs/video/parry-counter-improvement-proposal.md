# パリィと反撃の改善案（2026-10-12）

「スロー明けに素早く振り抜く」「パリィをもう少し派手にする」という相談から、追加指示「推奨される案も取り入れて、まとめて修正して」で採用された内容。強い暗転・瞳の残光・速い着地/受け身・攻撃前進/ヒットバックも反映した。

## 反撃：タメと振り抜きを分ける

前版は回し蹴り18〜28Fの全区間を0.25倍にし、命中時にスローを解除していた。足を前に伸ばす24〜28Fも遅いため、タメからの加速が見えにくかった。

| 区間 | 前版 | 採用した変更 |
|---|---|---|
| 18〜24F | 0.25倍、0.4秒 | 0.15倍、約0.667秒。引いた脚と重心のタメを見せる |
| 24〜28F | 0.25倍、約0.267秒 | 通常速度、約0.067秒で振り抜く |
| 28F命中 | スロー解除、8F停止 | 既に通常速度へ戻った状態で命中し、8F停止へ移る |
| 明るさ | 黒14%、命中から6描画Fで戻す | 黒82%、主人公の輪郭と瞳を残す。スロー解除から3描画Fで戻し、命中前に明るい画面へ移る |
| 命中後の動き | 54Fまで下降と復帰 | 28〜36Fに加速して下降、36Fで行動解放。続く7ポーズ/33Fの自由な復帰で自然に立ち上がる |

タメの実時間0.5〜1秒を保ち、解除から命中までの動きが約6.7倍に加速して見える。実測は4段295F/4.916667秒、2段234F/3.9秒。対象固定と、開始から36Fの着地までの無敵、敵のひるみ保持を維持した。自由にキャンセルできる地上復帰へ無敵を残さない。

24/26Fには足先をつなぐ短い軌跡を加え、解除直後へ瞳の残光を集中させた。清書では24Fと26Fの姿勢から28Fの接触までを一つの振りとして読める形にする。背面で瞳が見えないコマには光を出さない。

解除と着地は戦闘tickのEventにした。Pause/Hitstop/30・60・120fps、中断・対象消失と40回再実行を検証する。物理とAnimatorは既存の戦闘時計で進める。

## パリィ：剣を弾く方向と短いピークを強調する

現在の丸い輪を中心とする描画に、剣から飛び抜ける斜めの白い線を主役として加える。中心の白いFlashは1〜2描画F、金色の火花は6〜10描画Fで消す。全体の発光補助は採用済みの混合方式を使う。

撮影時のパリィVFXの大きさは0.75から1.05へ変更した。約1.4倍のサイズで、足・顔・敵の剣が読める範囲へ広げた。敵の剣が跳ね上がる姿勢と、上半身が後ろへ反る動きに線と火花を同期する。

停止は通常/Just Parry 2/3Fを維持した。見た目のピークを強めて短く抜ける構成とし、蹴りの大きな円状衝撃波と8F停止には別の強さを持たせる。成功点は鋭い線と火花、最後の撃破は大きな輪、という形の違いで無音でも読み分けられるようにする。

参照は受領した儀玄の映像の、短い明るいピーク、金色の方向線、黒い残像、反撃時の加速。粒子を長時間増やすより、弾いた瞬間に密度と輝度を集める案を推奨する。

## 暗転と移動の追加変更

- 敵の弾かれ4ポーズに、接触→後方へ反る→少し戻る→ひるみ保持の姿勢を加えた。足元と腰の下のドットは保持する。
- スロー中は黒82%、入り/戻り3描画F相当。主人公だけ通常色の像を不透明度60%で重ね、瞳は専用マスクで白青色の光と短い残光を出す。体や髪は発光させない。フェードと残光は実時間、Pause中は停止。
- 地上攻撃の前進は縦0.12/横0.20/連続0.28/居合0.40unit。敵ヒットバックは0.08/0.14/0.24/0.40unit、蹴り0.65unit。撮影設定だけに適用し、本編の4段設定は保持。
- 敵のヒットバックは戦闘tickで進め、壁で止める。撮影では既存の一律ノックバックを0にして二重移動を防ぐ。消滅VFXは移動する敵へ追従する。
- 中断・対象消失・Disable・Scene変更・リセットで暗転/主人公の像/瞳/時間/カメラを解除。旧Sceneの生成Materialも破棄する。

## 復帰と画面効果の追加

地上の無入力時に、各動作から普通の立ち姿へ戻る復帰を加えた。追加の行動ロックはなく、歩きや全行動の入力でキャンセルする。コンボや反撃入力があると復帰を挟まない。通常攻撃は16〜18F、パリィ15F、蹴り33F。蹴りは手を離す、膝/上体を起こす、髪/衣服が落ち着く順で、瞬間的な立ち姿への切替を解消する。

揺れは斬撃の方向ごとに0.04→0.055→0.075→0.11unit、パリィは斜め0.095、蹴りは強い反動0.20、着地は縦0.065unitへ調整。一定の振動から、最初の反動と短い揺り返しが減衰する方式へ変更した。蹴り命中には2描画Fだけの弱い画面Flashも加える。カメラを複数箇所から動かさず、同じ所有者がアップ/位置/揺れを合成し、Pauseでは停止する。
