## Unityとドット作画の分担

| 内容 | 主な担当 | 具体的な分担 |
| --- | --- | --- |
| 接触の止め、揺れ、ズーム、暗転、短い画面Flash | Unity | 実際の成功/命中イベントに同期する。作画へ停止コマや画面全体の色を焼き込まない。既存実装あり |
| 瞳の発光、残像の数・位置・透明度、消える/現れる時刻 | Unity | 瞳マスクと身体Spriteを再利用。光の強さと寿命を後から調整する。既存実装あり |
| パリィ火花、粒、衝撃波、落雷の配置・大きさ・再生時刻 | Unity | 既存の独立したドットVFXを接点へ重ね、短い発光を補助に使う。粒は現在もドットSpriteによる表現 |
| 踏ん張り、肘/腰の圧縮、押し返し、脚の振り下ろし | 主人公の作画 | シルエットと重心で動きを伝える。Unityの平行移動・拡縮だけでは自然な身体の形を作れない |
| 刀/足に沿った短い振り跡、最速コマの変形 | ドット作画 | 身体や武器に密着する部分。今回の青いEffectはそのまま採用。身体とは別レイヤーにする |
| 瞬間移動の崩れ方、輪郭が線状へほどける形 | ドット作画＋Unity | 特有の形だけ作画。Unityが出発/移動中/到着の表示位置と透明度を制御。現在は既存姿勢の複製・拡縮で代用、新しい移行素材の接続は受領後 |
| 火花の星形、鋭い衝撃輪、枝分かれした落雷の形 | 独立したドットVFX＋Unity | 絵柄を決める輪郭はドット。Unityで再生・色・短い補助光を調整。主人公の各コマへ丸ごと描き込む必要はない |

作画の優先度は「身体の力の流れ → 刀/足に密着した軌道 → 必要な移行の変形」。粒や画面効果を先に増やす必要はない。接触点の火花は明るい芯・暗い外縁・短い飛沫で白背景でも読ませ、主人公の顔と刀を隠す時間は短くする。パリィを最終段以上の全面発光にはしない。

## 新しい2種類のスプライトの配色案

基本方針は **移行で色数を絞り、追撃で通常色を戻す**。画面の暗さや半透明はUnity側で調整する。提出用の身体は透過背景・基本不透明で描き、ぼかした光は別にする。

現在の演出は、反撃開始時に身体を隠して影を残し、頭上到着後のスローで強く暗転する。画面暗転は最大0.965、主人公は暗転の上へ通常色を約0.6の強さで重ね、瞳はさらに上へ表示する。したがって、移行は白い通常背景でも見える必要がある。追撃を暗転用の黒い絵で描くと、輪郭と蹴る脚が暗所へ沈みやすい。

| 素材 | 推奨色・情報量 | 明るさの使い方 |
| --- | --- | --- |
| 反撃へ移る瞬間移動 | 既存の濃紺 `#222034` と暗い紫灰 `#343148` を主体に2〜3色。進行方向の縁や刀先へ少量の青/青灰。元の輪郭が分かる形から細長い影へほどける | 暗い芯で白背景に残す。明るい縁は部分的に1px程度、瞳だけ小さく高輝度。全面を白や水色にせず、暗転途中でも縁/瞳が読めるようにする |
| 追撃のタメ〜かかと落とし | 現在のキャラ色を維持。髪/服は `#F3F5FB`・`#D8DCE9`、輪郭/黒衣は `#697C86`・`#222034`、肌は通常色。刀や軌道の青は必要箇所だけ | タメ中に頭・胴・上げた踵の形を読ませる。瞳は淡い青白、命中の最も明るい白は落雷へ集中。全身を同じ白に塗りつぶさない |

配色は既存パレットを軸にした提案であり、新しい色をすべて追加する指定ではない。顔・手・足は通常色でも十分読めるため、細部を増やす必要はない。光を受ける側の輪郭を数か所だけ残せば、暗転中も立体的に見せやすい。

瞳は通常の青い瞳のまま描き、別レイヤー `CleanUp - eye glow mask` に「発光させる瞳だけ白、その他は透明」を用意するのを推奨する。開閉・顔の向きに合わせてマスクも動かす。瞳の色を変更しても、服や刀を誤って光らせずに済む。身体・刀/軌道・瞳マスク・ガイドを分け、ガイドとマスクは通常表示から隠す。

移行と追撃は別ファイルでよい。人物の大きさは待機と同じ32PPU、右向き、足裏と原点を共通にする。広い余白が必要なら身体を縮めずキャンバスを広げる。128pxなら従来と同じPivot(32,38)を引き継げるが、キャンバスのどちら側へ余白を増やしたかも伝える。

現在のゲーム時刻は反撃開始0F、移動2F、スロー開始18F、解除24F、命中28F、着地/終了36F。スローは実時間約2/3秒で、解除から命中までは4戦闘F。新しい移行素材を受領した時に、その絵を使って消失・到着までを再配分する。既存の0〜18Fをすべて描く必要はない。追撃はスロー中のキーポーズ、解除直後の振り下ろし、命中、着地が判別できることを優先する。
