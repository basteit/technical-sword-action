# 試遊版フィードバック（2026-11-08）

目的: 入力してすぐに動け、敵の合図と反撃の位置関係を追いやすい試遊版にする。

## 今回の受入条件

1. Fキーの代わりに数字キーで練習・リセット・演出調整ができる。通常攻撃は従来より早く発生し、入力した向きと絵・判定が揃う。通常の2段上限と防御キャンセルは維持する。#34 / #41
2. ジャンプは上昇・下降を短くしつつ高さを大きく変えず、壁に向けて入力し続けても落ちる。実際の着地にだけ足元の小さなVFXを出す。#84 / #33
3. 焼き込みの黄色い予兆はタイミングを変えず、白背景でも読めるようにする。カメラを落ち着かせ、背後が壁でも安全な正面位置があれば反撃する。敵との間に壁がある場合は反撃せず、使用権を消費しない。#43 / #33 / #44

## 今回の変更

- 数字キー・テンキーの1〜9をF1〜F9の操作に、0をF10のテンポ比較に追加。Fキーと画面ボタンも残す。
- 2段攻撃はFASTを初期値にする。発生は60fps換算で1段目15→12F、2段目12→9F。0で従来のORIGINALと比較可能。剣の表示・判定・攻撃中の移動方向を左右入力に合わせる。
- 試遊シーンのジャンプ初速を12→13.2、重力倍率を3→3.63にする。上昇・下降を速めつつ、短押しジャンプと既存の9コマの切り替えを維持。プレイヤーの衝突材だけを低摩擦にし、着地に左右へ広がる小さなエフェクトを出す。
- 既存の黄色い予兆光に濃い金色の1ピクセル縁を付ける。合図のタイミング、敵の本体、パリィ判定は変更しない。
- カメラの揺れと寄りは初期値オフ。6で演出を戻せる。現行の蹴りは溜めを約0.89秒→約0.27秒にし、暗転を弱める。背後の経路がふさがる場合は、手前に移動して蹴るか、届くなら横移動せずその場から蹴る。敵との間に壁がある場合は反撃しない。
