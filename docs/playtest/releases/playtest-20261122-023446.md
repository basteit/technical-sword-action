# Windows試遊版 2026年11月22日

ストーリー／戦闘の2モードと、モニタールームのタイトル画面を含む試遊版です。

## ダウンロードと起動

1. `Keraunos-Windows.zip` をダウンロードし、「すべて展開」してください。
2. `TechnicalSwordAction-Prototype` フォルダ内の `TechnicalSwordAction.exe` を起動してください。
3. タイトルでボタンを押し、「ストーリー」または「戦闘」を選んでください。

Windows 10 / 11・64bit向け。Xbox互換ゲームパッド、キーボード／マウスに対応しています。詳しい操作は同梱の `README.txt` をご覧ください。

## 今回の内容

- タイトル：5列×3段の壁モニターにロゴを表示し、手前のテレビへ接近してモードを選択します。研究所風の仮背景、配線・機器、モニター光、弱いぼかし、約14秒周期・約4秒で通過するノイズを追加しました。
- ストーリー：森の導入、移動チュートリアル、暗転によるエリア移動、剣との会話、パリィ・戦闘・回復チュートリアルを通して遊べます。回復せずに先へ進むこともできます。
- 戦闘：敵のまとまりを倒すと次のウェーブへ進み、最後の小ボスとの一騎打ちで終了します。
- ポーズ画面と終了画面から、やり直しやモード変更ができます。

## 仮素材・調整中の部分

- 背景、会話、敵の見た目や強さなどに試遊用の仮素材・仮調整が含まれます。

- 公開ページの戦闘映像は2026年10月の演出サンプルです。
