# Windows試遊版 2026年11月22日・タイトルの発光とライティング強化

[スマホ確認ページ](https://basteit.github.io/technical-sword-action/title-preview/?v=lighting3)で、実際のゲーム画面の12秒動画、登場直後の画像、前回と今回の通常時の比較を確認できます。

- 通常時にもロゴの周囲へ柔らかい発光を加え、文字の明るさと存在感を強めました。
- ロゴ登場時は発光と部屋への光をさらに強くし、約2秒で通常時へ落ち着きます。
- 壁、モニターの筐体、機器、机や床に青白い光が広がるように調整しました。
- 画面内へ部屋の光が重ならないようにし、ロゴとモード選択の文字を読みやすくしています。
- 5列×3段のモニター、細い継ぎ目、ゆっくり流れるノイズ、ストーリー／ウェーブ式戦闘の2モードを含みます。

ZIPを「すべて展開」し、`TechnicalSwordAction-Prototype` 内の `TechnicalSwordAction.exe` を起動してください。操作は同梱の `README.txt` をご覧ください。

背景・会話・敵の見た目などは試遊用の仮素材を含みます。作業中の未コミット変更を含むビルドで、識別情報は `BUILD_INFO.json` に記録しています。

タイトル入力・画面合成・モード切り替えなどの関連PlayModeテスト10件を確認済みです。
