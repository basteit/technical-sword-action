# パリィのカジュアル化・初回比較（2026-11-18 / #34）

体験目的: 予兆を見て少し早めに構えた場合と、少し離れた相手にもパリィから共通反撃を試しやすくする。

## 受入条件

1. PrototypeCombatValidationの受付を0〜13Fから0〜17F、距離を2.5uから3.0uへ変更する。Just0〜3F、高低差1.5u、空振り全体の終端26F、クールダウン14F、威力、敵の攻撃範囲は維持する。
2. 17F・距離3.0uを含む境界で成立し、18F・距離3.01u・高低差1.51uでは成立しない。軽/重、左右、空中、Pause、壁越し・不可攻撃の拒否と同じ距離での共通反撃を確認する。
3. 既存の比較切替・リセット・移動・短反撃と重パリィへ退行を残さない。自動検証と実画面の確認を記録し、人の15分比較・物理パッド・最終数値採用は分ける。

成功時: 予兆を見て構えた入力が成立し、間を空けずに短反撃へつながる。
失敗時: 時間切れ・遠すぎる・高低差・壁・不可攻撃では成立せず、失敗硬直と再操作へ戻る。連打で受付を延長し続けない。

変更するのは受付と距離の2軸。今回の値はユーザー指定による試用値で、標準難易度の最終決定ではない。本編共通のクラス既定値、他の作業中Scene、受領素材、サウンド依頼表を変更しない。既存ブランチ/PRの後続コミットとして#34へ紐づける。

失敗時は終端26Fを保つため、受付終了後の硬直は13Fから9Fへ短くなる。受付延長から自動的に生じる配分変更で、空振り全体とその後のクールダウンを短くする調整ではない。
