# 試遊フィードバック追調整（2026-11-11）

体験目的: 通常攻撃からパリィ・反撃へ、敵の接地やプレイヤーの操作を壊さず素早くつなぐ。

対象: #107、作業ブランチ `issue/107-combat-stability`。

## 受入条件（着手前）

1. 上下差のある通常攻撃を繰り返しても敵が床へ沈まず、足場から敵へ落下しても本体接触で停止しない。ダメージ・パリィ・反撃・撃破は有効なまま、通常攻撃では敵をひるませない。
2. 反撃受付の終了前後にAttack/Parry/Dashを重ねても、排他状態と実行中の処理が一致し、操作不能・意図しない仮Sprite・無敵/重力/表示の残留を起こさない。反撃は開始時の主人公側から敵の反対側へ抜け、地形が塞ぐ場合は安全な手前へフォールバックする。
3. プロトタイプではQとゲームパッドを含む必殺技入力を無効にする。通常画角を少し近づけ、白背景でも診断文字を読める背景と文字色を付ける。通常攻撃の既定は保存済みSNAPPY（1/2段9/7F）とし、ORIGINAL/FAST比較と2段上限を保持する。

成功時: 入力に素早く反応し、反撃の進む向きが現在の位置関係から理解できる。
失敗時: 受付切れは通常攻撃へ戻り、壁越し反撃は成立しない。拒否・中断理由を診断表示へ残し、操作や表示をロックし続けない。

## 検証記録

### 原因と修正

- 敵の沈下: 通常被弾の方向ベクトルに鉛直成分が入り、地形判定なしでrootを動かしていた。さらにRigidbodyを持たない静的な敵ではCollider2D.Castが0件となることを実測（同位置のBoxCastはGroundを1件検出）した。世界座標の形状で床・壁をSweepする。現在の通常敵2体と無限HPダミーは通常被弾の硬直/押し戻し/やられ絵を無効化し、パリィ/反撃/撃破だけで崩す。共通機能・強ザコ用のひるみ設定は残す。
- 落下時の接触: 最初の接触コールバック後にIgnoreCollisionする方式を、物理計算前の設定へ変更した。Dashの一時的な衝突無視が終了した後も再適用し、敵無効化時は元の設定へ戻す。
- 必殺技: 検証SceneのSpecial実行コンポーネントを無効化し、入力RouterのSpecial Actionも無効化する。Qだけでなくゲームパッドと直接Action要求も成立しない。製品の実装と素材は保持する。
- 仮表示/復帰: 反撃がタイマー更新で終了した後、専用Sprite所有者が解除されて汎用Counter Clipが1描画Fだけ露出する経路を防いだ。行動が変わった同tick内にAnimatorの次姿勢を評価する。パリィ/反撃状態に実行処理が存在しない異常時は次tickにNeutralへ戻し、診断の `Inactive action recoveries` と遷移理由へ記録する。未使用の別個体の受付と入力を一律破棄しない。
- 反撃位置: 開始時の主人公→敵のX方向で通り抜け先を決め、到着後は敵へ向けて蹴る。敵の向きは使わない。壁際の手前フォールバックと地形遮蔽、選択した1個体への1Hitを維持する。
- 試用: SNAPPY 9/7Fを既定、通常カメラSize5（約12.5%拡大）。白背景でも読める濃色パネル、白文字と14pxの操作ラベルを使用する。演出の寄り/揺れ初期OFFと8Fの通常命中停止は維持する。
