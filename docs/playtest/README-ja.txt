ケラウノス（仮）― 戦闘プロトタイプ試遊版
======================================

この版について
--------------
Windows 10/11 64bit向けの、基本操作と戦闘の手触りを試す開発途中の版です。
今回は、移動・ジャンプ・着地・床抜け・ダッシュ・2段攻撃・パリィ・反撃を試してください。
髪付きのジャンプ、ダッシュの残像、敵の前面に見える黄色い予兆光が入っています。
一部の絵や演出には仮素材を使用しています。
UnityやSteamのインストール、ログインは不要です。Mac・スマートフォン用ではありません。
動作環境の下限や全PCでの動作は未確認です。

起動・終了
----------
1. ZIPを右クリックして「すべて展開」してください。ZIP内から直接起動しないでください。
2. 展開したフォルダ内の TechnicalSwordAction.exe を起動します。
   .exeだけを移動せず、同梱の_Dataフォルダ・DLLなどをすべて一緒に置いてください。
3. 画面をクリックしてから操作してください。最初は敵がいません。
4. F1で通常敵、F4で倒れない練習ダミーを1体出せます。F2で敵なしの初期状態へ戻ります。
   画面右上の対応するボタンでも同じ操作ができます。
5. 終了はウィンドウ右上の×、またはAlt+F4です。Escは終了ではなく一時停止です。

やり直し・演出の調整
--------------------
F1  通常敵1体との戦闘を最初からやり直す
F2  敵なしに戻し、位置・HP・状態をリセットする
F3  通常敵2体を出す
F4  HPが減らない練習ダミー1体を出す
F5  通常敵と練習ダミーを1体ずつ出す
F6  カメラ演出（揺れ・寄り）の強度を切り替える
F7  フラッシュの強度を切り替える
F8  装飾エフェクトの強度を切り替える
F9  音量をON/OFFする
画面の揺れや光が強いと感じた場合は、F6/F7/F8で弱められます。

試してほしいこと
--------------------
まずは次の順番で一度ずつ、その後は自由に試してみてください。

1. 移動・ジャンプ・着地
   左右に歩き、左側の足場へ跳び乗ってください。
   ジャンプボタンを早く離す場合と、押し続ける場合の高さを比べてください。
   細い足場では、下入力とジャンプを同時に押して下へ抜けられます。
   足場から降りたときや着地したときに、動きや足元が不自然でないか見てください。

2. 地上・空中のダッシュ
   地上でのダッシュと、ジャンプ中のダッシュを試してください。
   空中ダッシュは着地まで1回です。着地すると再び使えます。
   移動距離や速さ、終了後の動きが扱いやすいかを見てください。

3. 2段の通常攻撃
   攻撃ボタンを押し直して、1段目から2段目へつなげてください。この版は2段で止まります。
   押しっぱなしで自動連打する方式ではありません。
   各段で止めたときの戻り方、ダッシュやパリィへのつながりも試してください。
   地上だけでなく、ジャンプ中にも攻撃できます。

4. 敵との戦闘・パリィ・反撃
   F1で通常敵を1体出します。敵の攻撃前の動きを少し観察してください。
   敵が近くで黄色く大きく光るタイミングを目安に、パリィボタンを押してください。
   成功して敵がよろめいている間に、近くで攻撃ボタンを押すと専用の反撃が出ます。
   よろめきは通常約3秒で、一時停止や命中時の停止中は時間が進みません。
   敵が立ち直ると、攻撃ボタンは通常攻撃に戻ります。
   撃破後はF1でもう一度戦えます。同じ相手に繰り返し試すならF4を使ってください。

操作が戻らない、表示がおかしいなどの場合も、まずF2でリセットしてください。

----------------
・未完成のアニメーションや仮の音・演出を含みます。
・製品版のタイトル画面、設定画面、ステージ進行、セーブ機能はこの試遊の対象外です。
・現在の試遊状態や検証プリセットは終了すると引き継ぎません。
・画面のフラッシュやカメラ演出がつらい場合はF6/F7/F8で弱めるか、一度終了してください。

  不安があれば実行を中止してください。セキュリティ機能を無効にする必要はありません。

不具合・感想を伝えるとき
------------------------
次の点を中心に、配布者へ感想を（フォームで）伝えてください。
・動かしにくかった操作、押したのに反応しなかった操作
・ジャンプ・着地・ダッシュや、攻撃のつながりで気になったところ
・パリィのタイミングが分かったか、成功後に反撃を出せたか
・気持ちよかった攻撃、当たったか分かりにくかった場面
・カメラ・光・音の強さで気になったところ

不具合の場合は、BUILD_INFO.jsonのbuildId、操作機器、使用した敵の設定（F1〜F5）、直前の操作、
起きたこと・期待したことを添えてください。画像や短い動画があると助かります。
ログが必要な場合の場所:
  %USERPROFILE%\AppData\LocalLow\DefaultCompany\technical-sword-action\Player.log
ログにはPC情報などが含まれる場合があるので、公開前に内容を確認してください。
