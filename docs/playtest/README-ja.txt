ケラウノス（仮）― 戦闘プロトタイプ試遊版
======================================

この版について
--------------
Windows 10/11 64bit向けの、基本操作・戦闘を試す開発途中の版です。
この版は通常攻撃2段まで。髪付きのジャンプ、ダッシュの残像、敵の前面に見える黄色い予兆光が入っています。
UnityやSteamのインストール、ログインは不要です。Mac・スマートフォン用ではありません。
ステージ攻略や物語を含む完成したゲームではなく、検証用メニューと仮素材を含みます。
動作環境の下限や全PCでの動作は未確認です。ビルド識別情報はBUILD_INFO.jsonに記載しています。

起動・終了
----------
1. ZIPを右クリックして「すべて展開」してください。ZIP内から直接起動しないでください。
2. 展開したフォルダ内の TechnicalSwordAction.exe を起動します。
   .exeだけを移動せず、同梱の_Dataフォルダ・DLLなどをすべて一緒に置いてください。
3. 画面をクリックしてから操作してください。最初は敵がいません。
4. F1で通常敵、F4で倒れない練習ダミーを1体出せます。F2で敵なしの初期状態へ戻ります。
   画面右上の対応するボタンでも同じ操作ができます。
5. 終了はウィンドウ右上の×、またはAlt+F4です。Escは終了ではなく一時停止です。

まず試してほしいこと
--------------------
・A/DとSpaceで動き、左側の足場へ着地する。細い足場は下から・横からすり抜けられます。
・攻撃ボタンを押し直して1段目から2段目へ。この版は2段で止まり、押しっぱなしでの自動連打はありません。
・F1で敵を出し、近くで敵が黄色く大きく光るタイミングを目安にパリィを押す。
・成功すると敵が約3秒よろめきます。その間に近くで攻撃を押すと専用の反撃が出ます。
  立ち直った後は通常攻撃です。よろめき時間は一時停止・ヒットストップ中は進みません。
・F4の練習ダミーはHPが減らず、パリィと反撃を繰り返し試せます。
・被弾・死亡後に戻れないなど、比較しにくいときはF2でやり直せます。

検証用キー
----------
F1  通常敵1体             F2  敵なし・位置・HP・資源などをリセット
F3  通常敵2体             F4  無限HPダミー1体      F5  通常敵 + 無限HPダミー
F6  カメラ演出（揺れ・寄り）100% → 0% → 50%
F7  フラッシュ強度        F8  装飾VFX強度          F9  音量ON/OFF
画面左上のShow Debugで内部状態を表示できます。通常の試遊では開かなくて構いません。
