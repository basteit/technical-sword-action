# 重パリィ・短反撃の試遊修正（2026-11-17）

体験目的: 重パリィの衝撃と後退、通過後の構え・納刀・遅れて発生する一撃を、敵1体で繰り返し確認できるようにする。#101 / #85、既存ブランチとPR #114で扱う。

## 受入条件

1. 5/F5/テンキー5は重攻撃専用の無限HP敵1体。4の軽攻撃無限HP敵、1/3の通常敵、各比較切替・リセットを維持する。
2. 重成功後の無操作復帰で軽パリィの終端・復帰アニメを出さない。停止中は軽と同じ左右の描画揺れを出し、解除後は約1.25u後退する。壁、空中、Pause、中断で位置・表示・重力を残さない。
3. 短反撃は移行8Fの後、最初のコマ10Fを保持し、納刀27F、攻撃35F、終了44Fとする。納刀SEと斬撃SEを分け、納刀前・待機中にダメージを与えず、選択対象へ1回だけ命中して通常操作へ戻る。

成功時: 構えから納刀、遅れて一撃が入る間を読め、重の踏ん張りから通常姿勢へ自然に戻る。
失敗時: 地形で後退を止め、中断・消失では未発生の斬撃や音を残さず操作へ戻る。

数値は今回の確認用。原稿のコマ・ファイル・履歴は変更しない。キャラクター揺れはカメラ強度と分け、初期100%、0/50/100%を画面のボタンで切替可能にする。人による手触りの最終採用、15分操作、物理パッド、Buildは自動検証と区別する。
