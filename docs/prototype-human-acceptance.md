## 準備と記録

1. 同じコミットの `Assets/Scenes/PrototypeCombatValidation.unity` を開く。古いSampleSceneや撮影Studioを、この受入の設定値と混同しない。
2. Game Viewを16:9、可能なら1920x1080にする。背景は動画用の既存白グリッド、床は灰青色一色を再利用する。初期状態は敵なし。敵の仮図形は任意の戦闘プリセットで有効にし、本制作アートの完成判定には使わない。
3. キーボード／マウスとXbox互換ゲームパッドを用意する。デバッグのShow Debugから状態・入力、攻撃・反撃、敵・被弾を切り替える。
4. 日付、コミット／Build、機器、設定、成功／失敗数、問題の再現手順とスクリーンショット／動画を残す。調整は一度に最大2軸。問題が出た項目は未合格のまま記録する。

### 検証Sceneの操作

| キー | 内容 |
| --- | --- |
| F1 | 任意の戦闘検証：通常雑魚1体 |
| F2 | 敵なし、Player・資源・位置・時間・入力・計測をリセット |
| F3 | 通常雑魚2体：反撃ストックの検証 |
| F4 | 重量強ザコ1体 |

| F7 | Flash 100 → 0 → 50 → 100% |
| F8 | 装飾VFX 100 → 0 → 50 → 100% |
| F9 | Master音量 100 ↔ 0% |

これらは検証専用のキーであり、製品版の設定画面ではない。演出設定はPlay中のコピーへ反映し、原Assetは書き換えない。0%でも予兆と最小の接触形は残し、ダメージ・受付・Hitstopは変えない。リセットは比較用の演出設定を維持し、Playを終了すると原設定へ戻る。

## 1. 基本操作・入力（#49 / #42）

- [ ] 白グリッドが動画用の背景と同じ見た目で、新規背景が不要な状態になっている。初期状態とF2後に敵が出ない。左の通常ブロックと2段のすり抜け床へ順番に登り、床抜け後に安全な床へ着地できる。右の平地で空中行動を試せる。
- [ ] キーボード／マウスとゲームパッドを各15分操作し、Move、Jump、床抜け、4段Attack、Dash、Parry、Counter、Special、Heal、Interact、Pause、Hit、Death、Respawnを一巡する。
- [ ] Bを有効Interact対象あり／なし各10回。ありはInteractだけ、なしはDashだけ。対象が押下直後に消えても遅延Dashしない。ShiftとEは独立。
- [ ] J＋LMB、K＋RMBを同時入力しても二重発火しない。空中のAttack／Parry／Dash／Specialが使え、空中Dashは着地まで1回。
- [ ] ジャンプの高さ・早離し・端からの猶予・先行入力、下＋Jumpの床抜けが意図どおりで、壁・床・敵との衝突が残留しない。
- [ ] Healの適用前に被弾すると回数を消費せず、適用後なら回復と消費を維持する。回復中の40%歩行、3回上限、死亡復帰後の補充を確認する。
- [ ] Pauseを地上、空中、床抜け、被弾、Hitstop中に操作し、再開時の攻撃／Dash暴発、無敵・速度上書き・時間倍率の残留がない。死亡・落下・復帰を10回繰り返す。

## 2. 通常攻撃・反撃（#44 / #49 / #42）

- [ ] 地上・空中の4段攻撃を各10回。1段につき同じ敵へ1Hit、段飛ばし・入力抜け・終了不能なし。キャンセル硬直の開始／最終Fとその直前／直後に次段、Parry、Dash、Specialを試す。
- [ ] 復帰では移動・Jump・Heal・Interactを含む通常行動が使え、Attackは1段目から始まる。納刀の接続、敵への接触位置、絵と判定のずれを確認する。最終モーションの品質は#50へ記録する。
- [ ] F3でA→Bをパリィして2件、A→Aは1件で残り時間を更新する。通常／ジャスト成功とも初期値3秒のよろめきが見え、その間だけAttackで反撃し、終了後は通常攻撃へ戻る。一時的な範囲外・通常被弾でも残り時間は進み、対象死亡時はその対象だけ消える。Pause・Hitstop中は減らない。
- [ ] 反撃は選んだ1体だけへ命中し、開始時に1件だけ消費する。他の敵へ自動で切り替えず、未使用の別対象分は残る。押し続けで連発せず、終了前6Fの追加入力で次を1回だけ予約できる。
- [ ] 反撃の防御キャンセル、対象消失、中断、死亡、Disable、リセットで拘束・無敵・入力予約・演出が残らない。

## 3. 通常雑魚と強ザコ（#43 / #52）

- 敵の配置確認は現在保留。以下は戦闘受入を再開するときだけF1・F3〜F5で明示的に有効にする。

- [ ] 最初の5分は攻撃せず観察し、通常雑魚と重量強ザコを色以外の体形・構え・テンポから区別できる。
- [ ] F4の通常斬撃と低いパリィ不可の払いを発生前に区別できる。通常斬撃はParry、払いはJumpまたはDashで対処でき、後隙へ反撃できる。
- [ ] 通常雑魚は初期水準で反撃1回で撃破、強ザコは満タンHP120から基準反撃90を受けてHP30で生存する。これは設定値の確認であり、自動即死ルールではない。
- [ ] 敵定義のmaxHp／反撃倍率と、Damageable2Dの配置個体上書きをEditorで別々に変更し、同じ定義を使う別個体を巻き込まないことを確認する。終了後は元の値へ戻すか、採用する変更を別コミットとして記録する。
- [ ] 強ザコは軽い攻撃では簡単にひるまず、4段目・反撃・Specialでは通常時にひるむ。不可攻撃の構え／Active中の耐性が予兆と矛盾せず、HPだけで長くなりすぎない。

- [ ] 通常攻撃、反撃、DashからのAttack、Specialを使って両方を撃破し、敵のひるみ・撃破・再配置が破綻しない。
