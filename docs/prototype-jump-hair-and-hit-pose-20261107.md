# ジャンプの髪と仮の被弾表示（#84 / #34）

受領した髪の動きで上昇・降下を読み取りやすくし、被弾は立ち姿と押し戻しで分かるようにする。

1. `Player_jamp` の9コマの受領版をCurrent/Historyに登録し、原稿のレイヤー・時間と旧版を保持する。
2. 踏切1〜3の後、上昇4↔5、実際の頂点付近6→7、下降8↔9を表示する。移動の物理、早離し、空中行動を変えない。
3. 非致死の被弾中は待機の立ち姿を使い、ノックバック、HP、無敵、被弾演出、死亡を変えない。

`[仮置き]` 上昇は各3戦闘F、下降は各6戦闘F。上昇の短い区間でも両方のコマが見えるようにし、下降は原稿の100msに合わせる。頂点の速度閾値は従来どおり（+4、+1.25、-1.25unit/s）。床抜けと足場からの落下は下降ループを使う。
