# 軽パリィ: 弾きと引きの調整 (#33)

体験目的: 接点から敵側へ散る火花と、停止が解けたときの敵の反動で「刃を弾いた」と読めるようにする。失敗時は新しい演出を出さず、既存の成否の手掛かりを保つ。

受入条件:

1. 火花の総数は維持し、左右どちらでも接点から敵側へ流れる。停止解除時に敵の絵だけを押し返し、物理位置・当たり判定・ダメージは変えない。
2. 停止解除と同じフレームでカメラが緩やかに戻り始める。復帰時間、停止時間、敵の予備動作、反撃への直接接続は維持する。
3. 左右・描画速度・Pause・揺れ0%・中断時の後始末を関連テストで確認し、通常の予備動作から始まる軽パリィ単体を録画する。

重パリィと描き起こし素材はこの変更の対象外。

## 試作設定と戻し方

`CounterCinematic.asset` と `CounterLaunch_ReferenceTrial.asset` で調整する。火花は全32本のうち24本が敵方向、残りは短い返り火。 `parryDirectionalSparks=false` で前の放射状に戻せる。 `parryEnemyReleasePixels=0` で解除時の表示反動だけを無効化する。現在は最大4px（32PPU）、弾き切りの8Fに沿って減衰する。仮表示の敵の停止中の揺れはそのまま。

カメラは戻りの開始と長さ（0.18秒）は維持し、`parryCameraReturnCurve` の先頭キーの左右接線を 3 → 0.25 に変更した。前の戻り方が必要なら接線を3に戻す。反撃への引き継ぎは別設定のまま。

## 作画メモ（提案）

- Asepriteでは `ContactFlash`、`SparkFan`、`HeavyRing` を分ける。各素材の全コマは透明背景・同じキャンバスと接点ピボット。右へ弾く原稿だけ作れば、左はUnity側で反転できる。32PPUを目安に、切れないサイズから始める。
- 軽パリィの火花は長い線3〜5本と小さい粒。敵の斜め上に偏らせ、反対側に短い粒を少し。白黄の先端、橙の胴、濃い橙の縁で、白グリッドでも線を読めるようにする。接点の短い点灯 → 細長い線 → ちぎれた暗い粒の順。刀と顔の輪郭は残す。
- 重パリィは軽の絵に、同じ接点を中心とする中抜き・一部が欠けたリングを1枚重ねて広げる。描いたリングは画面の歪みとは別。明滅や火花の数を重ねるより、輪のシルエットと敵の大きい反動、別の低い打音で重量を出す。重さは敵の攻撃の性質で、ジャスト入力とは別に扱う。
