# 軽パリィ: 弾きと引きの調整 (#33)

体験目的: 接点から敵側へ散る火花と、停止が解けたときの敵の反動で「刃を弾いた」と読めるようにする。失敗時は新しい演出を出さず、既存の成否の手掛かりを保つ。

受入条件:

1. 火花の総数は維持し、左右どちらでも接点から敵側へ流れる。停止解除後は敵を後ずさりさせ、よろめき姿勢になってもその座標に留まる。ダメージは変えない。
2. 停止解除と同じフレームでカメラが緩やかに戻り始める。復帰時間、停止時間、敵の予備動作、反撃への直接接続は維持する。
3. 左右・描画速度・Pause・揺れ0%・中断時の後始末を関連テストで確認し、通常の予備動作から始まる軽パリィ単体を録画する。

重パリィと描き起こし素材はこの変更の対象外。

### のけぞり強化

目的: 軽パリィ成功で、敵の上体がはっきり押し返されたと読めるようにする。

1. 停止解除時だけ敵の絵を敵側に押し、足元を基準に反らせる。左右で鏡写しにし、物理位置や判定を動かさない。
2. パリィ失敗、予備動作、停止中、重パリィには変更を入れない。既存の弾き切り時間内に減衰し、カメラと反撃への接続は維持する。
3. Pause・揺れ強度・中断で押し出しと傾きが同じように停止または解除されることを確認する。

### 姿勢を固定した後ずさり（表示のみだった旧版）

目的: 一瞬の位置ずれではなく、弾かれた敵が同じのけぞり姿勢で後ろへ滑る動きを読めるようにする。

1. 接点のセルと20°の傾きを固定し、停止解除から弾き切りの8Fにかけて最大32px後ろへ動かす。
2. 後ずさりは描画のみ。よろめき・反撃の開始、カメラ、物理と当たり判定は維持する。反撃なしなら既存のよろめき姿勢へ移ってから表示位置をなじませ、反撃開始時は表示の残りを解除する。
3. 失敗や重パリィには適用しない。左右・描画速度・Pause・中断を確認し、等倍で後ろへ動く区間を確認する。

### 後ずさった位置に留まる

目的: 軽パリィで弾いた敵が、よろめき姿勢に入っても前へ滑り戻らないようにする。

1. 軽パリィで敵本体と判定を8戦闘Fで最大32px移動し、壁の手前で止まる。揺れの設定で距離は変わらない。
2. 絵と角度は後ずさり中に固定。よろめき姿勢へ切り替えても最後の座標を維持し、描画だけの横ずれを残さない。
3. 反撃の受付・カメラ・ヒットストップは維持し、この後ずさりが原因で反撃の射程から外れないようにする。失敗・重パリィ・撮影専用シーンには追加しない。

## 試作設定と戻し方

`CounterCinematic.asset` と `CounterLaunch_ReferenceTrial.asset` で調整する。火花は全32本のうち24本が敵方向、残りは短い返り火。 `parryDirectionalSparks=false` で前の放射状に戻せる。停止解除後の後ずさりは `parryEnemyReleasePixels=32`（32PPU）、傾きは `parryEnemyReleaseLeanDegrees=20` に固定。弾き切りの8戦闘Fで本体と判定を一緒に動かし、到達した位置で既存のよろめき姿勢へ切り替える。傾きだけを切るには `parryEnemyReleaseLeanDegrees=0`、後ずさりを無効にするには `parryEnemyReleasePixels=0`。

地形は吹っ飛びと同じ障害物レイヤー・当たり判定の大きさで調べ、水平の後ずさりは一方通行足場の側面を無視する。反撃の距離判定では、このよろめき中の同じ敵が実際に後ずさって広がった横距離だけを差し引く。壁・向き・高さ・背後到達の判定と実際の反撃位置には補正をかけない。

カメラは戻りの開始と長さ（0.18秒）は維持し、`parryCameraReturnCurve` の先頭キーの左右接線を 3 → 0.25 に変更した。前の戻り方が必要なら接線を3に戻す。反撃への引き継ぎは別設定のまま。

## 作画メモ（提案）

- Asepriteでは `ContactFlash`、`SparkFan`、`HeavyRing` を分ける。各素材の全コマは透明背景・同じキャンバスと接点ピボット。右へ弾く原稿だけ作れば、左はUnity側で反転できる。32PPUを目安に、切れないサイズから始める。
- 軽パリィの火花は長い線3〜5本と小さい粒。敵の斜め上に偏らせ、反対側に短い粒を少し。白黄の先端、橙の胴、濃い橙の縁で、白グリッドでも線を読めるようにする。接点の短い点灯 → 細長い線 → ちぎれた暗い粒の順。刀と顔の輪郭は残す。
- 重パリィは軽の絵に、同じ接点を中心とする中抜き・一部が欠けたリングを1枚重ねて広げる。描いたリングは画面の歪みとは別。明滅や火花の数を重ねるより、輪のシルエットと敵の大きい反動、別の低い打音で重量を出す。重さは敵の攻撃の性質で、ジャスト入力とは別に扱う。
