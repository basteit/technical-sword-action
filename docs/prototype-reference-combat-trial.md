# 動画準拠の敵調整と通常攻撃テンポ比較（#34）

## 体験目的

敵の長い予兆からパリィで姿勢を崩し、低く吹き飛ばす流れを読みやすくし、通常攻撃は元の手触りと高速試用版をすぐ比較できるようにする。

## 実装前の受入条件

1. F1/F3/F5の通常ザコで、参考動画と同じ96Fの予兆・24Fの攻撃後表示、パリィ後のdown姿勢、回転しない低い吹っ飛びを確認できる。HP30・攻撃10・倍率3・反撃受付180Fと判定形状は維持する。強ザコは対象外。
2. 通常攻撃の高速試用版は4段を保ち、命中12/9/12/30F、各段1対象1Hit、共通キャンセルと復帰中の1段目再開が成立する。実際の描画と命中差は2F以内。威力・ゲージ・Hitstop・パリィ受付は変更しない。
3. 敵の尺、やられ/吹っ飛び、通常攻撃速度を別々に比較し、元の全設定へ戻せる。切り替えは安全リセットを伴い、途中の判定・拘束・暗転・時間倍率を残さない。Pause/Hitstop、左右、壁/床、リセットを自動検証し、人による15分比較は未実施として残す。

成功時は敵の崩れた姿から反撃へ移る気持ちよさ、失敗時は接触前の予兆と実際の判定の一致を重視する。速度試用でパリィ受付を短くしたり、HPを増やして難しくしない。

| 敵のやられ | chance姿勢 / 3.2×0.65unit・22F・回転あり | down姿勢 / 1.6×0.27unit・18F・回転なし | 姿勢と吹っ飛びプロファイルの2軸 |

## 比較操作・戻し方

- `PrototypeCombatValidation` を再生すると全試用ON、敵なしで開始する。F1で通常ザコ、F3で2体、F4で元の強ザコ、F5で混成。
- **F10**：主人公の高速/旧速度。**F11**：通常ザコの96/24Fと旧30/30F。**F12**：down＋低い吹っ飛びと旧chance＋回転する吹っ飛び。既存F6〜F9の演出設定は変更しない。
- 右側の `#34 Combat trial` パネルでも切り替えられる。`Restore ALL original settings` は3比較をすべて旧版へ戻す。比較は一つずつ切り替える。
- 切り替えは現在の遭遇構成を保ってHP・位置・入力・演出をリセットする。途中の攻撃を継続したまま数値だけを変えない。会話中も安全リセットで閉じ、終了入力を攻撃へ流用しない。
- PlayMode内の切り替えは保存しない。再生を終了して再開するとSceneに保存した既定（全ON）へ戻る。継続的に旧版を使う場合は、非再生中に `PrototypeArena` の `PrototypeCombatTrial` の3チェックをOFFにしてSceneを保存する。
- 元の `FourStepAttack.asset` / `NormalMelee.asset` / `CounterCinematic.asset`、原稿とAnimationClipは上書きしない。独立した末尾 `_FastTrial` / `_ReferenceTrial` の3設定と、高速用の4派生Clip・専用Animator Overrideを追加する。速度を戻す際は定義とControllerを同時に元へ戻す。

## 検証と人による確認

実装後に自動結果・画面証跡を追記する。人による確認では各比較を一つずつ15分行い、試行数、パリィ成功率、理由を説明できない被弾、期待外の挙動を記録する。ゲームパッド、実ビルド、操作感の採否は自動テストで代用しない。
