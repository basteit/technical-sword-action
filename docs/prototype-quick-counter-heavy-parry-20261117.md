# 短反撃・重パリィの受領ラフ統合（2026-11-17 / #101・#85）

体験目的: パリィから短い納刀斬撃へ転じ、重い攻撃を受けたときは踏ん張りと後退の違いを同じ検証場で確かめる。

## 受入条件

1. 移行→通り抜け→構えの保持→納刀→少し待って1撃→立ち姿と操作復帰を表示し、旧キックへ安全に戻して比較できる。
2. 重パリィの接触姿勢をヒットストップ中に保持し、停止解除後に剣を地面へ突き立てる姿勢と後退を見せる。地形を貫通せず、反動だけで共通反撃を範囲外にしない。
3. 5/F5（上段/テンキーを含む）で重攻撃専用の無限HP敵1体を呼べる。左右・空中・壁際・複数対象・期限/中断/リセット・Pauseで状態、無敵、対象拘束、表示、時間倍率を残さない。

成功時: 納刀に納刀音、遅れて発生する斬撃に命中音が一致し、入力ごと次の個体へ続けられる。軽/重のどちらからも同じ反撃へつながる。
失敗時: 期限切れ・対象消失・地形遮断では余分なダメージや入力ロックを残さず、次の操作へ戻る。

## 初回の仮設定（以下は修正前の履歴）

- 短反撃: 移行8F、通り抜け4〜8F、納刀/1撃16F、終了24F、命中停止8F。原稿の500msを実装の固定尺にはしない。
- 元のキック用Profile、Clip、素材は保持。画面右上のCounterボタンで切り替え、現在の遭遇を安全リセットする。
- 重: 8コマの3コマ目を接触姿勢に使い、既存の敵ピーク同期と停止30Fを使う。停止後の表示18F、後退0.625u/14Fを初期値とする。Normal/Justの受付0〜13F/0〜3Fと距離2.5u・高低差1.5uは今回変更しない。
- 空中では重のリアクション中だけ高さを保つ仮設定。専用テスト初回で、18Fの表示中の落下が反撃を範囲外にするケースを検出したため。終了/中断/リセットで元の重力を復元し、通常終了では元の鉛直速度も戻す。被弾・死亡の新しい外力を復元処理で上書きしない。
- 短反撃の対象は通り抜け後の背面にも選べ、開始時に次の対象側へ向く。旧キックの前方条件は保持する。重の後退分だけ受付距離を補償し、普通の移動や対象の移動を距離補償へ混ぜない。
- 5は通常敵＋重攻撃専用の無限HP敵。4は従来の軽攻撃無限HP敵へ戻す。重攻撃は検証用で、新5階級や赤攻撃の全量実装を意味しない。
- カジュアル化の受付・距離の比較は今回の素材統合へ混ぜず後続とする。確認してから数値を採用する。
