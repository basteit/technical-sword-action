# 受領ジャンプ・ダッシュと近距離全方向パリィ（#84 / #34）

体験目的: 自作した移動モーションで行動段階を読み取り、近くの敵の攻撃は互いの向きに邪魔されずタイミングを合わせて弾けるようにする。

## 着手時の受入条件

1. 原稿はregisterでCurrent/不変Historyへ登録する。ジャンプ7コマを踏切1〜3、上昇4、頂点5〜6、落下7へ分け、ダッシュ3コマは地上/空中で共用する。髪未完成・着地専用原稿未受領を区別し、原稿・旧サンプル・完成動画を変更しない。
2. パリィ可能攻撃のActive時に、距離1.9unit・高低差1.25unit内なら主人公/敵の左右と攻撃方向、攻撃Hitboxの接触有無を問わず成功できる。予兆だけ、受付時間外、遠距離、高低差過大、壁越し、不可攻撃は成功させず、同一攻撃の二重処理を防ぐ。弾いた実個体だけのよろめき/反撃と主対象への振り向きを維持する。
3. 表示/方向条件の2軸だけを変更する。移動・可変ジャンプ・空中Dash回数/無敵・攻撃・パリィ受付/成功精度・カメラ・SEは保持する。関連EditMode/PlayMode、Pause/Hitstop/Reset/中断と左右の画面を確認し、人の15分操作は別に残す。

成功時: 段階が見えるジャンプと、向きが逆でも狙ったタイミングで弾ける気持ちよさ。失敗時: 距離・高さ・時刻・不可・地形のいずれが原因か説明でき、通常被弾判定を不当に広げない。
