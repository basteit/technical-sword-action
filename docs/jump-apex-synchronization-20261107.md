# ジャンプ頂点の速度同期（#84）

体験目的: 上昇・最高到達点・降下の実際の動きに姿勢を合わせ、頂点の前後で自然に4→5→6→7へつなぐ。

## 着手時の受入条件

1. 踏切1〜3の後は通常上昇を4で保持し、頂点に近づいた上昇だけ5、頂点前後を6、降下開始後を7とする。5→6を経過Fで送らず、実際の鉛直速度に同期する。
2. ジャンプ高さ・重力・可変ジャンプ・通常移動/地上Dashの直前調整を維持する。床抜けと足場離脱では踏切/頂点表示を誤再生せず、空中行動・Pause/Hitstop/Resetの表示所有権を保持する。
3. 30/60/120fpsと押し続け/早離し、頂点付近での表示・境界を検証する。既知13失敗は内容を正確に診断・説明し、動画設定やテスト期待値の修正は今回勝手に行わない。

成功時: 上昇で4が安定し、速度が落ちると5→6、落ち始めると7へ移る。失敗時: 見た目だけの修正によって高さや入力受付が変わらず、各姿勢の理由を速度と状態から説明できる。

## 決定と仮置き

- `[確定]` 最新指示に従い、直前の「頂点へ入って6F後に6へ送る」方式を廃止する。原稿と物理軌道は変更しない。
- `[仮置き]` 4: 鉛直速度>+4、5: +4〜+1.25、6: +1.25〜-1.25、7: <-1.25unit/s。踏切1〜3は従来のまま。表示閾値はArtSetで調整する。
- 今回の変更軸はジャンプの姿勢選択のみ。既知失敗の調査は診断に留める。#84の同一依頼の追調整として現在のブランチ/PRへ追加する。

## 検証

- Compile Error0 / Warning0、EditMode 343/343。関連PlayMode 69件中56合格・13失敗で、既知の13件と失敗名/Assertion文面が全件一致。新しいジャンプ31/31、素材統合7/7は合格。
- 通常ジャンプの実行では、4=10F/上向き7.094996、5=17F/上向き3.661497、6=22F/上向き1.208997、7=28F/下向き1.734003unit/s。最高root y=3.161660。経過Fは観測値であり、コマ選択の条件へ固定していない。
- 接地衝突で鉛直速度が0になり、次tickの接地判定までに頂点6が再表示される1Fの戻りを実行中に発見。降下へ入ったら接地/新しいジャンプまで7を維持するガードと、30/60/120fpsの落下→接地で頂点へ戻らないAssertionを追加した。
- [既知13件の診断](validation/known-playmode-failures-20261107.md)を記録した。今回の姿勢修正時点では期待値を変更しておらず、後続のユーザー依頼によるテスト整理は別コミットとする。
