# プロトタイプへの反撃演出接続（#33 / #49）

## 目的とDoD

体験目的: パリィで作った機会を、暗転・背後への高速移動・電撃キック・大きな吹っ飛びへつなげ、反撃が決まった爽快感を操作中にも得られるようにする。

2026-10-19のユーザー指示による仕様変更。以前の地上踏み込み反撃（18F命中・35F終了）に演出だけを重ねるのではなく、プロトタイプSceneだけ動画と同系統の反撃を選択する。#33 / #49の追補として、進行中の `issue/33-52-38-combat-polish` / Draft PR #78へまとめる。撮影側の構図・敵接近の並行作業は変更しない。

実装前の受入条件:

1. 本編用の専用設定から、移行0～12F（背後移動10～12F）、タメ12～20F（0.15倍、実時間約0.9秒）、命中21F、接地・終了45Fを実行する。受領済み移行8コマと最新キック15コマ、目の残光と寒色VFXを再利用し、暗転から確実に復帰する。2026-10-19の試遊後指示により、タメ開始から終了まで主人公をアップにし、通常終了で元の5.625と位置へ滑らかに戻し、中断時は即座に復帰する。共通Feedbackが寄りと揺れを合成する。
2. 弾いた個体を開始時に固定し、Attack一押しでストック1件だけ消費、同じ個体へ1Hitとする。通常の基準反撃90ダメージ、強ザコHP120→30、他個体のストック保持は維持する。反撃中は動画同様に無敵・任意キャンセルなし、終了前6Fの次反撃予約は維持する。壁・床を通過せず、背後への安全な経路がなければ開始前に対象を不適格としてストックを残す。命中した敵は最大3.2unit・高さ0.65unit・22Fで吹っ飛び、壁で止まる。
3. 地上／空中・左右・壁際・複数ストック・生存／撃破、Pause／対象消失／Disable／死亡／リセット／Scene変更を検証する。無敵、重力、対象拘束、暗転、目の光、VFX、吹っ飛び、時間倍率を残さない。揺れ・Flash・装飾VFXが0%でもダメージ・受付・反撃の移動を変えない。既存4段攻撃、歩行ガイド除去、パリィ移動停止、撮影の回帰を確認する。

成功時はタメから速い命中へ切り替わり、同じ相手が吹っ飛ぶことを読めるようにする。失敗時は壁越しに移動せず、対象喪失や中断で時間・表示を復帰し、別の敵へ勝手に反撃しない。暗転中に新しい入力待ちやQTEは追加しない。

## 確定と仮置き

- 確定: 暗転・背後回り・吹っ飛ばしをゲームプレイ反撃へ接続する。コントローラー以外の前版テストはユーザーが完了し、概ね問題なしと報告した。
- 仮置き: 上記の時間・距離・暗転強度は最新動画 `dcf5eda` / `fa800ea` を初期値とする。試遊後のカメラ拡大はOrthographic Size 1.875（通常の3倍）、主人公から攻撃方向へ0.45unit・上へ0.4unit、出入り各0.1秒を初期値とする。
- 既存の本編反撃は専用プロファイル未指定時の互換経路として残す。新しい値を撮影Sceneや従来の基本行動テストへ暗黙適用しない。
- 暗転・主人公の像・発光はFlash設定、装飾VFXと残像はVFX設定へ従う。0%でも通常の最小命中形は共通Feedback側から残す。時間と移動・無敵は演出強度から独立させる。
- カメラの寄りは揺れと同じカメラ演出設定へ従い、0%では通常の位置・画角を保つ。Pause中は補間も止める。
- 判定の接点は、動画原稿の足先座標へプロトタイプ表示子の足元補正を加えて設定する。原稿、PNG、ピボット、動画用時間配分を変更しない。

## 接続と再調整

- `CounterCinematic.asset`が本編専用の時間・暗転・吹っ飛び設定。`CounterCinematicArt.asset`は移行／キック／電撃VFXの3動作だけを持つ独立Snapshotで、撮影側の時間表更新が本編へ自動流入しない。
- 再接続は`Tools/Technical Sword Action/Prototype/Install Counter Cinematic`。既存Profileの調整値は残し、未保存の対象Sceneがあれば停止する。素材Installerの再生成時も専用Profileの反撃を維持する。
- `PlayerParryCounter2D`が対象固定・地形の事前検査・移動／無敵・命中を所有し、`PrototypeCounterPresentation`が時計に同期したSprite・暗転・スロー・VFXを所有する。共通Feedbackだけがカメラを動かす。
- `EnemyCounterLaunch2D`が地形に沿う吹っ飛びを所有する。`Damageable2D`の期限付き死亡表示と移動所有権により、致死Hitでも飛び終えるまで表示し、生存個体の通常Knockback／AIとの二重移動を避ける。足場から落ちた生存個体は接地まで落下を続ける。

## 2026-10-19 試遊後の修正

体験目的: 成功から反撃への流れを途切れさせず、左右どちらでも接点に合ったVFXと主人公のアップで反撃を読めるようにする。#33 / #49とDraft PR #78の追補。

- 成功表示: 反撃へ先行入力した際もパリィ通知を消化し、終了後へ成功モーションを遅延させない。通常成功・ジャスト成功とも同じ規則とする。
- VFX: プールの親である主人公の反転を二重に掛けず、発生時のワールド位置・向き・表示スケールを保持する。残像は実際の表示用SpriteRendererの姿を写し、発生後の移動や向き変更へ引きずられない。
- カメラ: `CounterCinematic.asset`に寄りの画角・中心オフセット・補間時間を持たせる。`PrototypeCounterPresentation`が所有者つきで要求し、`CombatFeedback2D`だけがカメラの位置・画角・揺れを合成する。通常終了は0.1秒で戻し、対象喪失・中断・死亡・Disable・Scene変更・リセットは即時復帰する。
- 失敗・中断時は対象やヒット数を変えず、表示・カメラの所有権を確実に返す。カメラ演出0%にしても反撃の移動・威力・時間は変えない。

実装コミット `c82d869`（基点 `6f5474c`）。CompileはError 0 / Warning 0。関連EditMode **13 / 13**、反撃SceneのPlayMode **48 / 48**、共通Feedback・パリィ・動画／Studioの関連PlayMode **319 / 319**が合格した。全体テストの再実施とは区別する。テスト後のF6ラベルの説明追加は、再コンパイルとGame Viewで確認した。

Game Viewでは14Fの暗転0.965・画角1.875、21Fの左右両向きでVFXと足先の接点・HP120→30を確認した。通常終了後は画角5.625、focus false、暗転・VFX・ストック・slow owner各0へ復帰し、入力と自動時計を戻して敵なしにリセットした。Console Error 0 / Warning 0、停止後は保存済みPrototypeCombatValidationのEditMode（dirty false）。人による15分の操作感、実機ゲームパッド、Development Buildは今回未実施。
