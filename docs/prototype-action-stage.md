## 目的と範囲

既存の動画用白グリッドを使い、敵に妨げられず移動・ジャンプ・空中行動・床抜けを繰り返し確認できるようにする。

2026-10-18のユーザー指示に基づく、#49の検証環境への追加調整。進行中の `issue/33-52-38-combat-polish` / Draft PR #78 上で統合する。SampleScene、BasicActionValidation、動画Scene、モーション、戦闘バランスは変更しない。

## 受入条件（実装前に定義）

1. `CombatVideoStudio.unity` にある既存の `WhiteGrid` と床の描画設定を再利用する。新しい背景画像・背景素材を制作せず、白グリッドと不透明な灰青色の床を表示する。
2. 低い通常ブロック1個と高さの異なるすり抜け床2個を配置する。ジャンプで順番に登れ、下＋Jumpで床抜けでき、右側に地上・空中行動用の平地を残す。
3. Scene起動時とF2リセット後には敵が0体となる。既存の敵と戦闘検証用プリセットは削除せず、明示的に選んだときだけ有効にする。

成功時は、見える足場へ操作どおりに乗り、空中行動から着地してすぐ再試行できることを重視する。失敗時は、足場の高さと端が読め、落ちても安全な床へ戻り、F2で無条件に最初から試せることを重視する。

## 2026-10-18 プレイ確認後の不具合修正（#49 / #30）

目的は、攻撃時のエラーログとすり抜け床の側面への引っかかりをなくし、入力どおりにアクションを試せる状態へ戻すこと。

修正前に定義する受入条件:

1. 実SceneのAnimatorを動かした地上・空中4段攻撃でAnimationEventのエラーが出ず、命中は各段1回、計測値も実ダメージと一致する。威力・時刻・Clipは変更しない。
2. 2枚のすり抜け床へ左右両側から入っても横面に止められない。上からの着地、下からのジャンプ、下＋Jumpの床抜けを維持する。通常ブロックと壁は固体のままとする。
3. 既存の回帰テストが通り、敵なし初期状態、白グリッド、既存の未コミット変更を保持する。

成功時はアニメーションと命中がそのまま成立し、空中移動で横端へ近づいても自然に通過できること。失敗時も見える通常ブロック・床面だけが障害物となり、見えない横壁のような判定で止めないことを重視する。

### 原因と修正

- 攻撃Clipの `OnAttackHit(int)` イベントが、同じGameObject上の `PlayerCombatTelemetry.OnAttackHit(Damageable2D, int, Vector2)` にも送信され、Unityで許可されない3引数の呼出しとしてエラーになっていた。計測用のC#イベントコールバックを別名へ変更し、購読・購読解除も揃えた。攻撃データ・Clip・命中処理は変更していない。
- `PlatformEffector2D.surfaceArc = 180` が薄いBoxColliderの横面まで含んでいた。検証Sceneの2枚を160度へ変更し、側面の摩擦・反発を無効にする設定を配置処理と検証へ追加した。今回の修正コミットに含めたScene差分はこの2個の角度だけで、白グリッド・位置・通常ブロック・壁・動画Sceneは変更していない。
- 前回の足場テストは上下移動が中心で、実Animator付き4段攻撃と足場の左右からの侵入を十分に確認できていなかった。今回は地上／空中・空振り／命中の4ケースと、2枚×左右×移動／Dashの8ケースを追加した。

修正前に同じAnimationEventエラーと横面停止を再現した。修正後の関連PlayModeテストは19 / 19合格。空振りの計測は0、命中は各段1回、4段の合計実ダメージと計測値は60で一致した。上からの着地・下からのジャンプ・床抜けと衝突復帰も維持している。
