# プロトタイプのダッシュ・反撃音・練習枠（#84 / #34 / #92 / #52 / #38）

体験目的: 長いダッシュから気持ちよく攻防を切り替え、倒れない相手で斬撃と反撃の手応えを繰り返し試せるようにする。

## 受入条件

1. 地上・空中の無障害Dashは仮値4.5unit（従来3.6unit、+25%）。主移動と無敵は12F、地上後隙2F、空中後隙8F、再使用待ち14Fと着地までの空中1回は維持する。壁は抜けず、実移動の後ろに現在の絵と向きで残像が出て短く消える。Pause・Hitstop中は停止、リセット・中断・無効化・演出0%で残留しない。
2. キックが実際に当たったときだけ、輪郭が鋭く広がりのある派手な衝撃音を1回鳴らす。空振り・中断で鳴らさず、既存の音量設定とゲイン上限を守る。タメの電撃音はOFFのまま、他のSE・判定・モーション・時刻は保持する。
3. F4は無限HPの練習ダミー1体、F5は通常ザコ＋練習ダミーとし、F1〜F5で強ザコを出さない。ダミーは命中・ひるみ・パリィ・反撃を受けても倒れず、同じ個体で反復できる。通常敵のHPと撃破、死亡再開、F2の敵なしは維持する。撮影専用のテストとそのSuiteだけを外し、ゲーム本体の回帰・撮影ツール・素材を残す。

## 変更の境界

- ユーザー指定の一括作業として進行中のPRに追加し、テスト整理、移動・表示、効果音、敵配置・HPを意図別にコミットする。
- 数値と音の質感は仮置き。プロトタイプSceneの設定へ限定し、撮影Scene、受領作画、製品の敵カテゴリやHP調整方針は変更しない。旧強ザコは選択できない状態にして既存の設定と回帰テスト用の非アクティブ個体を保持する。
- 自動テストは動作と境界を確認する。残像の読みやすさ、音の迫力・耳への負担、ゲームパッドの手触りは人の試遊で判定する。

## 試し方・調整箇所

- `Assets/Scenes/PrototypeCombatValidation.unity` を再生。Shiftでダッシュ。実移動があったときだけ2F間隔で青い残像を置き、9戦闘Fで消す。原画は変更せず、実際のポーズ・向きで描く。F8の装飾VFX設定（100/50/0%）に追従する。Inspectorの `PlayerMotor2D.dashSpeed` を18へ戻すと従来の距離、`PrototypeDashTrail` を無効にすると残像だけを外せる。
- F1は通常1体、F2は敵なし、F3は通常2体、F4は無限HPダミー1体、F5は通常1体＋ダミー。画面右上のボタンでも選択できる。F4/F5のダミーは通常ザコの攻撃と絵を使い、命中数とひるみ・吹っ飛びを受けるが、実HP減少・撃破は発生しない。F10〜F12の比較切替でも同じ枠を維持する。
- 無限HPはSceneの `TrainingDummy` にある `Damageable2D` の個体設定。通常ザコ、強ザコの定義や既存のHP設定はそのまま。再接続メニューは `Tools > Technical Sword Action > Prototype > Install Training Enemies and Feedback`。
- キックの音は `FreeSfx.asset` の `CounterHit`。4層の加工を `Tools/Audio/Import-PrototypeSfx.ps1` と出典台帳に記録した。F9のミュートは従来どおり。斬撃・空振り・タメの電撃OFFは変えていない。
